# Error as Travel Time

## Key Idea

Error is not just magnitude:
- it also encodes how long it takes to propagate

## Mechanism

If signal takes longer to reach deeper nodes:
- delay encodes structural information

## Learning Signal

Error includes:
- magnitude mismatch
- timing mismatch

## Example

Fast-changing signal:
- error arrives quickly
- system reacts with high α

Slow-changing signal:
- delayed propagation
- lower α

## Insight

Time delay becomes part of representation:
- network learns temporal structure
- not just value prediction
