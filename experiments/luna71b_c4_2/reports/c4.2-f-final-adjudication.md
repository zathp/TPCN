## Disposition rationale

The seed-17 plan records the three split digest pairs, four arms, balanced
class counts, and 48 ordered example IDs per split. R6's seed-17 digest
references match the plan. Neither artifact contains the event payload rows.
Consequently the required exact per-example input bytes, channels, timestamps,
deadlines, and encoding cannot be verified, and no driver-compatible frozen
payload manifest exists.

The plan's parameter snapshot is independently hashed from its exact
canonical JSON payload and matches the copied constructor values, Python
binary64 precision, and documented parameter order. However, R6 uses that
same digest for all seeds; it is not seed-17 proof. Historical source-to-run
lineage and fixture binding remain incomplete.

Static source inspection establishes capture insertion points only.
`SOURCE CAPTURE IMPLEMENTED` findings are not runtime traces, passivity
proofs, or parity. P03 expiration/settlement, P04 omitted-symbol resolution,
P07 expiry/capacity rejection, P08 corrective scheduling, P09 complete
ordered transitions, and runtime P11 stop evidence remain incomplete.
Conditional branches retain the C4.1 distinction between
`UNEXERCISED / NOT_EVIDENCED` and measured evidence; missing traces are not
zeros.

The paired interface is deliberately preflight-only and refuses callback
dispatch even after mocked successful preflight. It cannot prove two
independent mutable instances, produce distinct neural run traces, or perform
the full online P01-P11 comparison. The 34-test suite validates only
synthetic/schema/ledger/comparator behavior and two source-capture
corrections.
