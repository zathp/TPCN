## Future test suite (proposed, not run)

1. **Unit/API conformance:** constructor/config validation; immediate external
   event handling; internal event queue scheduling; emission conversion and
   topology routing; same-time ordering; positive delay; signed transfer.
2. **E1 state table:** isolated per-neuron tests for decay, state clipping,
   inclusive threshold, ordinary emission timing/amplitude/polarity,
   same-sign accumulation, opposing input, single-input non-crossing,
   rearm, and M-boundary refusal.
3. **Adapter integration:** B-X-D event identity, contributor map, state
   transition, transfer delay, D receipt and terminal empty queue.
4. **Counterfactual:** P/N/C/I/T/O+/O- acceptance and exact same-condition
   replay as defined in `06-m2d-counterfactual-protocol.md`.
5. **Failure/guard:** queue, E1, total-event, time, observer, artifact and host
   guard refusals; ensure no failure becomes success-shaped output.

All test commands and outputs belong to a future, separately authorized
implementation/qualification packet. None was run under M2D design authority.
