## Equations and event semantics

One local scalar z, initially 0, is evaluated only at input, scheduled return,
or terminal observation events. No global neural tick exists.
Before an event at t: z <- z exp(-(t-last) L/(R C)).
R/C/L are positive dimensionless resistance/capacitance/leakage multipliers.
Input x (including sampled bounded additive noise) is qualified if
abs(G x) >= 0.25 T + sign(x) O. Qualification uses gain before capacitance.
On admission z <- clip(z + G x/C, -8, 8). State clipping is recorded.
At any input or local return event, if abs(z) >= T:
y = tanh(z), emit one bounded signed output, then
z <- z - sign(z) min(abs(z), 0.75 T).
If still above T, schedule exactly one return at t+0.1. Inputs may occur
before that pending return; it then reevaluates current state. No output
is generated by an observation. All timestamps must be finite, nonnegative,
nondecreasing, and each scheduled return strictly future/representable.
Equal times: input first, then return, then observation, insertion order
within each kind. Inputs are supplied in declared order, never summed.
Output times and discharge states are retained. The queue holds only inputs,
one return and one observation. Reset discards all state/queue per fixture.
No inter-node route, predictive coding, credit, reward, topology, or physical
energy model is represented. Counts of local updates/outputs are proxies,
not joules and not efficacy or a full A01-A15 conformance demonstration.

These equations are independent experimental choices. Saturation and tanh
make some bounds true by construction: passing those checks tests this
implementation, not discovery of a hardware primitive. Mathematical tanh,
exact exponential evolution and ideal discharge have no claimed circuit
realization. Positive leakage has no equilibrium bias term; comparator
offset is not an integrator offset.

## Draws, bands, correlations, seeds and coverage

config.json and fixtures.json are the authoritative numeric definitions.
Bands b: nominal=0, selected=.02, general=.10, loose=.25, stress=.50.
Three seeds 470601/470602/470603, 256 samples per seed per band:
768 per band, 3,840 total. Python 3.11 random.Random uniform draws in fixed
order. Reset RNG per seed per band gives matched unit draws across bands;
bands are therefore paired, not independent.

Draw Ucommon, UR, UC, UG, UT, UL, UO, UN independently U[-1,1].
R=1+b(.5 Ucommon+.5 UR), C=1+b(.5 Ucommon+.5 UC):
R/C triangular marginals with theoretical correlation .5 for b>0.
G=1+b UG; T=1+b UT; L=1+b UL; O=.2 b UO;
noise_amplitude=.08(1+b UN). Remaining parameters independent, except
the same T scales both qualification and emission comparator thresholds.
Per fixture and event draw an independent U[-1,1] noise unit and multiply
by noise_amplitude; preserve those units too. Nominal includes bounded
input noise, so it is not a noiseless control. All fixture pairs use matched
noise and all fixture draws are independent within a sample.

Both physical polarities run at the same offset: x/noise are reversed.
Additionally run a mathematical mirror with O also reversed, expected to
agree to abs tolerance 1e-12. Physical equal-offset sign asymmetry is measured
and not assumed absent. Also run the zero-offset mirror as an applicable
symmetry control. Positive and negative meaningful regimes must both pass.
Cancellation, order sensitivity, timestamp shift (+123), irregular gaps,
finite idle decay and reset are unit-tested; cancellation/order fixtures are
retained diagnostic controls, not extra tuned verdict gates.

Deterministic corner interactions: for each of 21 pairs among R,C,G,T,L,O,N,
run four +/- b corners at loose and stress, holding other multipliers at
nominal, O corners at +/-.2b and N at .08(1+/-b), with identical noise
units from seed 470699 across all corners. R/C corner probes deliberately
override their sampling correlation; these are interventions, not frequency
estimates. 168 additional rows. No adaptive search or post-outcome tuning.

## Predeclared qualitative gates

Use exact threshold comparisons (no fuzzy comparator admission). Every
fixture ends with observation 20 time units after its last input. Bounds:
abs(z)<=8, abs(y)<=1, inputs abs(x)<=8, <=128 inputs, <=192 processed
events, <=16 outputs; budget exhaustion is an explicit failure, never a
silent successful truncation. Reject invalid nonfinite/late inputs.
Neutral: abs(final z)<=1e-6. Mirror/zero-offset/time-shift test tolerance:
absolute 1e-12. Replay: canonical JSON byte equality on the same environment.

Each signed sample must pass the ordered six gates:
1. ordinary noise: all 16 pure-noise inputs rejected, zero outputs;
2. meaningful single: one input admitted, pre-discharge peak>=.3, no output;
3. nearby accumulation: both near inputs admitted, peak>=1.5 times single
   peak, >=1 near output, zero far outputs (same meaningful inputs far apart);
4. moderate compression: all three moderate inputs admitted, exactly one
   output, abs(total output)<=.9 times total absolute admitted deposition;
5. extreme return: one extreme admitted, 2..16 outputs, >=1 local return
   output, strict-future returns, abs(total output)<=absolute deposition;
6. neutral: every fixture returns within 1e-6 by its terminal observation.
Record bounds and mathematical symmetry as separate mandatory gates.
Full sample fails if either physical polarity fails any gate, bounds fail,
or mathematical/zero-offset mirrors fail. All failed names and adjacent
passed->failed/failed->passed regime transitions retained per sample.
There is no suppression of failures by averaging.

Verdict: SUPPORTED only if nominal AND every band have <=1% failed samples
and zero safety/symmetry failures; PARTIALLY SUPPORTED if nominal meets this
gate and at least one nonnominal band does but not all; NOT SUPPORTED
otherwise. BLOCKED only if provenance/execution prevents valid evidence.
These are stand-in/fixture verdicts, never hardware yield statements.

## Analysis, hashes, uncertainty and publication

Per-band counts/fractions and Wilson 95% intervals (z in config) quantify
finite independent sample draws, not hardware-population confidence.
Nominal repeated parameter draws vary noise only. Three seeds are not a
model-error uncertainty estimate; zero failures does not establish zero risk.
Report each gate and polarity separately. Preserve complete parameter draws,
input noise units, event traces, outputs, saturation counts and criteria.
Sensitivity ranking: per-parameter high-vs-low quartile failure-risk contrast
and Pearson correlation with failure indicator in each band; ties handled
deterministically, zero variance correlation reported 0. Observational,
not causal, confounded by correlated R/C and shared T.
Corner interactions: all four failure indicators and difference-in-differences
f++ - f+- - f-+ + f--; binary saturation can mask interactions. Also preserve
per-corner gates and traces. Ranking is descriptive, not calibrated selection.

Canonical JSON: sorted keys, compact separators, allow_nan=False, final LF.
Sample/corner JSONL files use deterministic gzip with mtime=0 to retain full
event traces without exceeding Git hosting file limits; replay compares the
compressed bytes and hashes. Decompression yields one complete row per line.
Manifest identifies authorization/production/protocol execution revision,
Python/platform, raw file SHA256, Git blob SHA256 for source/protocol/fixtures,
configuration/fixture hashes and sample/summary file SHA256. Source blob hashes
avoid CRLF ambiguity; raw file hashes describe actual executed bytes.
Replay in memory is exact, followed by fresh-process --verify disk comparison.
Artifacts write only to artifacts/luna47g; reject canonical aliases outside
that directory and protect all tracked lane non-output files. No general
output override or overwrite of historical outputs unless --verify compares.
Protocol/code/tests/handoff preregistration committed before any tests or
outcomes. Outcomes and completed handoff committed afterwards with required
coauthor trailer, then branch pushed and clean/ref parity verified.

Limits: sparse synthetic inputs, static bounded uniform noise rather than
continuous stochastic forcing, no parasitics, temperature/supply drift,
cross-talk, colored noise, hysteresis, jitter, nonlinear capacitor/leakage,
device aging, metastability, rail recovery, integrator bias, or fabrication
distribution. Physical calibration/selection recommendations are hypotheses
conditional on this assumed model. Luna-0 independent review is the only next
authorized action; no integration, ACP, successor or architecture promotion.
