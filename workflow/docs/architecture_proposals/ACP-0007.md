## Current invariant or soft constraint

ACP-0006 §17 states:

> The first integrated path uses fixed topology and must run with structural
> plasticity disabled. No N3 edge adaptation or new candidate-evidence
> semantics are activated by integration. Static topology and its bounded
> Model-B parameters remain available. Structural adaptation may be
> reintroduced only under its existing local evidence contract and separate
> authorization; this proposal does not redesign it.

A14 supports bounded local structural adaptation. This accepted proposal
authorizes an optional, explicitly selected EXCURSION_V1 experiment path; it
does not make structural plasticity a default or mandatory core behavior.
ACP-0002 N2 remains unchanged. ACP-0002 N3 remains unauthorized. No neuron
equation, edge parameter (`w`, `d`, or `r`), prediction/error arithmetic,
readout algorithm, or hardware-equivalence claim is proposed.

## Observed problem

At baseline `d9abe5e3a5b9b3c6d6049ac4c64647463c33ba2d`, `ExperimentConfig`
rejects `EXCURSION_V1` with `structural_plasticity=True`. This preserves
ACP-0006's first-integration fixed-topology boundary. The historical
`ExperimentRunner._adapt_topology()` is not a conforming EXCURSION_V1 evidence
producer: it selects a source by example index, selects destinations from a
configured policy, scores with `abs(run.feature) + run.loss`, and prunes using
feature-derived scores. The score inputs are post-character experiment
summaries, not evidence shown to be locally available to the candidate source.

The Luna-12I `TemporalAssociationPolicy` is a bounded experimental policy
that emits the existing `CandidateEvidence` type. Luna-13F independently
supports runtime-generated source-local evidence in its declared fixture and
supports that the evidence affects canonical admission. Luna-13F does **not**
support useful-growth prediction, does not establish resource benefit, and
does not authorize use in normal EXCURSION_V1 training. Its runtime fixture
uses legacy `TPCNNeuron` and explicitly addressed candidate observations; it
does not define how a production E2 source obtains candidate observations from
the actual routed event path.

Luna-13D did not establish evidence-based pruning: its scores were assigned
by endpoint role, and changing the declared utility threshold did not change
the pruning decisions. Luna-13E concerns pre-admission candidate quality after
fixture pruning; it does not supply a local edge-retention/pruning evidence
contract.

## Proposed change

The project owner accepted this proposal **with the complete local
observation contract below** on 2026-10-04. This authorizes a separately
dispatched CPU EXCURSION_V1 growth experiment only; it does not implement
growth or promote it to the default.

### Explicit selection and policy

The ordinary/default configuration remains `EXCURSION_V1` with
`structural_plasticity=False`. Structural growth is opt-in. When E2 structural
plasticity is enabled, the only accepted policy identifier is
`e2_local_temporal`; the historical `baseline`, `random`, `temporal`, and
`reversed` policies are not E2 learning rules and must fail explicitly in
this mode. TANH_LEGACY's explicit compatibility behavior remains unchanged.
This mechanism is an experiment/integration choice, not a mandatory core
behavior and not evidence that growth is useful.

### Bounded structural-observation plane

The structural-observation plane is separate from neural routing,
prediction-error routing, TPCV, outer readout, reward, and IR-2. It exists
only to supply local structural evidence. Its only input is an actual
canonical `ExcursionEmission`; silent accumulator updates, prediction-error
events, rewards, TPCV snapshots, readout values, labels, and energy records
produce no structural observation.

For an emission `e` from node `j`, the plane exposes only
`(emitter_id=j, event_id=e.event_id, timestamp=e.timestamp)`. Event identity
may support deterministic uniqueness/deduplication only. No payload or
payload-magnitude value is visible to the structural scorer.

Each network configuration explicitly declares a static directed
`structural_neighbors[source]` list, independent of mutable neural topology.
The declaration must cover the network's sources, use valid distinct node
IDs, exclude self-neighbors, have deterministic ordering, and satisfy explicit
finite per-source neighbor and per-emitter reverse-observer limits. Neither
limit may silently default to all-to-all. A small test network may explicitly
declare every other node as a neighbor only when it satisfies those same
declared bounds. The bounded neighborhood is the hardware-visible
observation fabric; no unrestricted network scan or broadcast is permitted.
A software centralized dispatcher is allowed only when it implements these
same bounded local semantics.

The emitter observes its own emission. A source `s` observes emitter `j`
only when `j` is in `structural_neighbors[s]`. Thus only for those permitted
recipients is the equivalent of
`observe(observer=s, node=j, timestamp=e.timestamp)` delivered. Structural
observations never enter `MultiExcursionNeuron.receive_event()`, the character
queue, prediction/error processing, eligibility, readout, reward, topology
routing, or TPCV.

Observation work and retained state must be bounded by actual emission count,
the declared reverse-observer/neighborhood limits, per-source
`history_capacity`, per-source `candidate_capacity`, and
`maximum_score`. Observation ON with mutation disabled must preserve the
complete neural character result, including ordering, emissions, prediction
errors, eligibility/reward/readout, queue statistics, proxy energy, reset
state, and topology; only observer-owned bounded evidence may differ.

### Accepted temporal-association score

Only the bounded association-count mechanism represented by
`TemporalAssociationPolicy` is promoted, and only under the observation
semantics in this ACP and the separately authorized E2 growth experiment.
This does not promote Luna-13F fixture roles, utility claims, or task-benefit
conclusions.

For each observer/source `s`, an actual emission by `s` records a local
self-observation at `t_s`. A later observed emission by declared neighbor
`d` at `t_d` increments evidence for `s -> d` only when
`0 < t_d - t_s <= association_window`. Equal-time emissions do not form an
ordered association. Per-source history and candidate storage are bounded;
the score is the association count saturated at `maximum_score`. Candidate
identity is `(observer=s, source=s, destination=d)` with that bounded count.
Candidate endpoint locality and all other validation remain governed by the
existing `StructuralPlasticityController`.

Each growth-enabled experiment declares a finite positive
`structural_growth_delay`; the first mechanism does not learn delay. The
candidate uses that configured value, never task outcomes, prediction loss,
class, future arrival, or global path length. Existing deterministic
controller ranking/tie behavior remains authoritative.

### Evidence lifecycle and mutation

At character start, source-local histories, candidate scores, and
character-local candidate rejection counters are empty/reset. Actual
emissions feed them online; no post-hoc unrestricted trace is used. No
topology mutation occurs while the character runtime is active.

Admission is allowed only after `END_CHARACTER`, successful bounded settling,
a complete `ExcursionCharacterRuntime.end_character()` result, and destruction
of the character queue, route sidecar, pending internal work, prediction/error
delivery state, eligibility ledgers, and classifier state, with the runtime
inactive. At this post-character/pre-next-`START_CHARACTER` boundary, freeze
the evidence, make at most one deterministic growth attempt (and at most one
successful growth) for that character, then consume/discard the character's
evidence. Any incomplete settling, `execution.completed == False`, or
budget-exhausted character contributes no evidence and causes no mutation.

There is no evidence, history, or candidate carry-over across characters,
epochs, or experiment/model reset. The accepted grown topology persists across
later characters in the same experiment, as ACP-0006 defines. Experiment
reset creates a new model/topology namespace. Training character order is
causal and part of deterministic replay; the topology admitted after character
N may affect character N+1. No global timestep or epoch-wide mutation
boundary is introduced.

The experiment has an explicit finite growth-attempt budget; the existing
controller's candidate, edge, fan-in/out, routing, positive-delay, atomic
admission, and deterministic rejection semantics remain authoritative.
Growth uses the same `BoundedTopology` as later E2 routing. A bounded
convergent-fan-in fixture must remain possible within declared capacity.
Pruning is disabled and not authorized by this ACP. The existing historical
queued-event/pruning rule is unchanged but is outside this growth-only path.

### Information, metrics, and non-goals

The structural score must not consume labels, emission payload magnitude,
`prediction_loss`, reward, accuracy, prototype distance/state, outer readout
feature, utility, energy, confusion matrix, future events, or held-out
results. In particular, the historical E2 score
`abs(run.feature) + run.loss`, `run.feature`, `run.loss`, task correctness,
reward, accuracy, and example index are explicitly rejected as evidence.
Historical E2 endpoint policies do not become E2 learning rules.

The same-seed/config/input/character-order/evidence condition must reproduce
the same evidence, rank, decision, topology, and later routed trace. Changing
external labels or future suffixes cannot alter a completed frozen decision.
Changing non-neighbor emissions cannot directly change a source's evidence.
Capture-on/off must preserve all structural decisions. TPCV remains
downstream-only and is never a learning dependency.

Reports may include candidate/evidence and rejection counts, accepted growth,
connection and fan-in/out utilization, topology, processed events, edge
transfers, route depth, queue peak, prediction/readout metrics, and the
uncalibrated activity-cost proxy. These diagnostics are not structural
inputs. Mechanism acceptance requires legal, bounded, local, causal and
deterministic growth, not accuracy, prediction-loss, reward, or energy
improvement. Luna-13F remains **NOT SUPPORTED** for useful-growth prediction;
resource benefit remains **NOT ESTABLISHED**.

This decision does not authorize pruning, ACP-0002 N3 (`w`, `d`, or `r`
learning), neuron/state-machine changes, prediction/reward/readout changes,
IR-2 extension, downstream consumer migrations, GPU/FPGA/ModelSim work, or
hardware equivalence.

## Why implementation alone cannot solve it

The generic `CandidateEvidence` record validates types, finite score and
delay, endpoint membership, and `observer == source`; it cannot validate
where its score came from. The controller therefore cannot turn
`run.feature + run.loss` into source-local evidence by setting `observer` to
the chosen source. The E2 runtime currently provides actual per-character
routing and a quiescent destruction boundary, but no accepted structural
evidence adapter or cross-character evidence lifecycle. Selecting those
semantics would promote an experimental producer and define new integrated
behavior, not merely wire an already-complete producer.

## Expected benefits

This accepted decision permits a bounded test of whether a legal,
source-local EXCURSION_V1 topology mutation changes a later real routed
excursion. It clarifies a root dependency behind several blocked
structural/replay consumers while keeping structural efficacy separate from
mechanism validity.

## Expected disadvantages and risks

Local temporal association did not predict useful held-out growth in Luna-13F.
Growth may increase events, proxy energy, route depth, or harmful connectivity
without improving a task. A source may not locally observe the activity of a
potential destination in a unidirectional network; importing a central runtime
log would violate A07. Character-order learning can make later examples see a
different topology. Growth-only mode may fill finite capacity without a
validated retention policy. None of these risks is solved by removing the
configuration guard.

## Hardware implications

No hardware result is claimed. Any accepted evidence feed must use bounded
local state and finite delays and must not require a global neural clock,
unbounded event log, global topology search, or visualization dependency.
Software timestamps remain logical reference values until hardware units and
mapping are separately declared. No FPGA, FPAA, hybrid, or backend equivalence
is established.

## Learning and energy implications

Labels, held-out results, class prototypes, global accuracy, confusion
matrices, outer readout features, task rewards, and postprocessed prediction
loss must not become structural evidence unless a separate accepted contract
explicitly authorizes a particular local message and timing boundary.
Prediction/error, eligibility, delayed credit, and outer reward arithmetic
remain unchanged. Energy remains an uncalibrated activity-cost proxy; the
topology must not be selected solely to minimize that proxy.

## Compatibility and migration

The current E2 structural-mode guard remains effective until Luna-28
implements the accepted explicit `e2_local_temporal` mode; all other
structural policies remain unavailable for E2 growth. Existing TANH_LEGACY
behavior and the Luna-12E fixed-topology path remain available. TPCV-1/TPCV-2
remain downstream-only. IR-2 is not extended and is not a whole-network
structural checkpoint. Existing spiral, Luna-12L, temporal-analysis, and
viewer consumers require separate migration/review and are not
implementation dependencies of this experiment.

## Required experiments and acceptance criteria

The separately authorized Luna-28 dispatch translates this accepted contract
into focused tests. At minimum it requires:

- actual-emission-only structural observations, silence/error/reward exclusion,
  bounded static-neighborhood and non-neighbor controls, observation
  non-interference, equal-time rejection, source-before-neighbor association,
  score saturation, and explicit candidate-capacity accounting;
- post-character quiescent admission, no mutation while active, no growth on
  incomplete/budget-exhausted characters, evidence consumption/reset, and
  topology persistence vs experiment reset;
- label mutation, future-suffix immutability, deterministic ranking/replay,
  fixed-topology control, explicit policy/configuration validation, finite
  growth budget, and explicit capacity rejection without partial mutation;
- same-topology controller/computation, edge/fan-in/out and convergent
  capacity controls, observation-work bounds, pruning-disabled and N3
  invariants;
- at least one legal bounded candidate/admission route to useful convergent
  fan-in remains measurable under the declared capacity budget; capacity is
  not treated as an optimization target;
- capture-on/off decision equality;
- at least one admitted growth case that changes a later real delayed E2
  routed-excursion trace; topology existence alone is insufficient;
- separate reporting of mechanism status and task efficacy, with no required
  accuracy/prediction-loss improvement threshold;
- relevant ACP-0006, Luna-26, structural-controller, TemporalAssociationPolicy,
  Luna-13F, and TPCV-2 focused regressions.

No Luna-13F useful-growth claim, A14 promotion, N3 work, hardware acceptance,
or downstream-consumer migration follows from passing this mechanism gate.

## Rollback plan

The fixed-topology EXCURSION_V1 path under ACP-0006 §17 remains the default
and safe rollback configuration. The E2 growth mode is explicitly opt-in; a
failed or reverted implementation leaves that fixed-topology path and its
configuration guard available.
