## Scope and preserved invariants

ACP-0002 N2 is closed and remains authoritative for:

```text
z_ij = tanh(w_ij * a_i)
v_ij = d_ij * z_ij + (1 - d_ij) * r_ij
```

Contributions retain finite positive propagation delay and deterministic
equal-time ordering. ACP-0003 H1 is independently closed; `TPCN-IR-1` remains
its current scope. A01-A15 remain unchanged.

This proposal is a future canonical-neuron architecture change. It does not
authorize ACP-0003 H2, ACP-0002 N3, a production backend, calibration,
hardware-equivalence work, Luna-19, Luna-13F reopening, or Luna-13G.

## Canonical terminology and cardinality

The backend-neutral object is a **canonical excursion**, not a spike, CUDA
operation, FPGA clock pulse, or analog voltage. The required reference mapping
is:

| Canonical meaning | GPU/software and FPGA reference | FPAA realization |
|---|---|---|
| One excursion | exactly one digital emission event | one physical spike or analog excursion under a later approximation contract |
| Multiple excursions | multiple digital emission events | multiple physical spikes or analog excursions |
| Timestamp | deterministic logical transition time | physical peak/crossing is observational |

The rejected draft wording “one or more TPCN events” is not implementable
without an identity/framing contract. Any exception requires a new proposal.
Compression is distinct from multi-excursion encoding:

```text
C_E = N_input_contributions / N_output_excursions
```

For GPU/FPGA reference observables, output excursions and output events are
one-to-one. FPAA counts physical excursions subject to its later tolerance
contract.

## Proposed state and accumulation

Persistent canonical dynamical state is:

- signed bounded accumulator `x`, with `-X_max <= x <= X_max`;
- local last-update timestamp.

Bounded execution bookkeeping consists of mode, ordinary-return phase,
generator arm/disarm state, pending excursion identity and captured polarity,
bounded amplitude, provenance/lineage, truncation state, and a finite set of
pending internal emissions. An independent persistent `y` is not required;
any future addition requires evidence that `x` plus bounded bookkeeping loses
causal information.

For an arrival at local time `t_k`:

```text
x(t_k-) = x(t_(k-1)+) * exp(-lambda * (t_k - t_(k-1)))
x(t_k+) = clip[-X_max, X_max](x(t_k-) + v_ij(t_k))
```

There is no global neural timestep. Equal-time arrivals are processed
sequentially in the established deterministic sequence order.

## Operating regions and ordinary return

Parameters satisfy:

```text
0 < theta_E < theta_M <= X_max
0 <= theta_hold < theta_M
```

Exact regions are:

```text
N: |x| < theta_E
S: theta_E <= |x| < theta_M
M: |x| >= theta_M
```

Membership is evaluated after each ordered accumulation or due internal event.
`N -> S` and `N -> M` occur on post-update membership. An active ordinary
return does not emit repeatedly merely because input remains in `S`; `S -> M`
is permitted on the exact boundary. A new ordinary excursion is not eligible
until the prior return completes in `N`.

An ordinary return must begin from accumulated state, follow a distinct
bounded return trajectory, emit exactly one excursion, terminate finitely, and
converge toward neutral without new input. Its exact geometry is not yet
canonical and remains an acceptance blocker.

The amplitude contract is:

```text
p_exc = sign(E) * A_exc
0 <= A_exc <= A_max
A_exc = f(|x_peak|)
```

`f` must be deterministic, finite, bounded, monotone over its declared range,
and explicit about saturation. Polarity must be captured when an excursion is
admitted so later input cannot mutate an already identified payload.

## Multi-excursion return

Entry is exactly `|x| >= theta_M`. The generator has bounded state:

```text
h_min <= h <= h_max
h_L < h_H
```

`h_L` and `h_H` are oscillator-domain values. They must not be compared
directly with `theta_hold`, which is an x-domain value. The draft condition
`h_L >= theta_hold` is rejected.

Each generator cycle must define armed state, trigger, one emitted excursion,
disarm, re-arm, and next-excursion eligibility. The first-stage discharge rule
is:

```text
x <- sign(x) * max(|x| - Delta_x_E, 0)
Delta_x_E > 0
```

This cannot cross zero or reverse polarity. M remains active while
`|x| > theta_hold`, exits at `|x| <= theta_hold` into ordinary return, and
then reaches N.

With no new input, the discharge bound is zero when
`|x_0| <= theta_hold`, otherwise:

```text
ceil((|x_0| - theta_hold) / Delta_x_E)
```

This proof requires finite generator-cycle duration and explicit fixtures for
`|x_0| = theta_M`, `|x_0| = X_max`, negative state, and zero crossing.

## Inputs, autonomous timing, identity and provenance

An input during either return is decayed, accumulated, clipped and retained;
it cannot disappear. It may promote `S -> M`. It must not retroactively mutate
an emitted payload. The exact pending-amplitude, generator-extension,
opposite-sign, cancellation and rescheduling tables remain blockers.

Autonomous return progression requires bounded internal neuron events at finite
future logical timestamps, never a hidden timestep loop. The revised proposal
must specify positive finite ordinary and inter-excursion delays, timestamp
calculation, external/internal equal-time ordering, pending-event capacity,
and cancellation/rescheduling.

Every digital emission has a unique non-negative identity/sequence and
timestamp. Excursions from one episode may share a bounded lineage identifier.
Provenance must declare finite capacity `P`; the required overflow policy is
oldest-contributor eviction plus a `provenance_truncated` flag. Complete
delayed-credit attribution must not be claimed after eviction.

## Predictive coding and Model-B migration

Accumulator changes remain local internal evidence. Predictions and explicit
prediction errors remain causally propagated events. Bounded provenance and
lineage must support the declared delayed-credit behavior or disclose its
attribution limitation. Labels, future data and global evaluation state remain
outside canonical neuron state.

After excursion migration:

```text
a_i := signed excursion payload p_exc
```

The existing Model-B transfer therefore consumes the emitted payload. The
former continuously recomputed `tanh(g_j * s_j)` value is an internal
compatibility/diagnostic value, not a second canonical output stream.

Legacy continuous output may remain only as an explicitly named, trace-labelled
compatibility mode. It cannot silently coexist as a second canonical behavior.
Excursion state, modes, pending events, payload and provenance require an
explicitly versioned schema, strongly expected to be `TPCN-IR-2`; IR-1 must
reject excursion records rather than silently reconstruct them.

## Hardware, learning and required evidence

Canonical state, local timestamps, finite delays, bounds, event identity and
return transitions must remain hardware-neutral. FPGA clocks, CUDA scheduling,
FPAA component values, analog voltage and physical spike width are backend
details, not canonical requirements. No backend implementation or equivalence
claim is authorized by this draft.

The proposal preserves local predictive coding, explicit error events, delayed
credit, local energy accounting and A01-A15. Compression may discard temporal
detail; bounded provenance must make that limitation observable. No learning
rule is introduced here.

Before implementation authorization, deterministic fixtures must cover:
subthreshold no-emission, close temporal accumulation, spaced leakage,
moderate one-excursion anti-burst behavior, extreme multi-excursion behavior,
finite return, signed symmetry, equal-time ordering, recurrence bounds,
input during both return modes, compression, prediction/error compatibility,
provenance truncation and batched/unbatched equivalence without a global
timestep.

## Review decision

**ACP-0004 REMAINS DRAFT - NOT ACCEPTED FOR STAGED IMPLEMENTATION.**

Acceptance is blocked by:

1. complete ordinary and multi-excursion transition tables;
2. exact positive finite autonomous timing and equal-time ordering;
3. input-during-return, cancellation and rescheduling semantics;
4. finite provenance capacity and overflow behavior;
5. amplitude saturation and polarity rules;
6. one-event identity and bounded lineage semantics;
7. versioned IR migration, expected to require `TPCN-IR-2`; and
8. deterministic finite-return and bounded-work fixtures.

If later accepted, the smallest first stage is **E1 - static leaky accumulator
plus single-excursion return**. It must exclude the multi-excursion generator,
learning, approximation and IR-2 implementation until separately authorized
and verified. No Luna-19 dispatch is created by this draft.
