This ACP authorizes only the hardware-neutral E1 architecture and its

## Canonical terminology and cardinality

The backend-neutral object is a **canonical excursion**, not a spike, CUDA
operation, FPGA clock pulse or analog voltage.

| Canonical meaning | GPU/software and FPGA reference | FPAA realization |
|---|---|---|
| One excursion | exactly one digital TPCN emission event | one physical analog spike/excursion under a later approximation contract |
| Multiple excursions | multiple digital TPCN emission events | multiple physical spikes/excursions |
| Timestamp | deterministic logical transition time | physical peak/crossing is observational |

The rejected wording “one excursion -> one or more events” is not canonical.
Compression is distinct from multi-excursion encoding:

```text
C_E = N_input_contributions / N_output_excursions
```

For GPU/FPGA reference observables, output excursions and output events are
one-to-one. FPAA counts physical excursions subject to a separately declared
approximation tolerance.

## Canonical parameters and bounds

The first canonical reference configuration uses logical time units and:

```text
lambda = 1
X_max = 8
theta_R = 0.25
theta_E = 1
theta_hold = 1.5
theta_M = 4
Delta_t_E = 0.5
Delta_t_M_emit = 0.5
Delta_t_M_rearm = 0.5
Delta_x_E = 1
A_min = 0.25
A_max = 1
P = 16
P_max = 64
```

Implementations may use another declared configuration only within:

```text
0 < theta_R < theta_E <= theta_hold < theta_M <= X_max
lambda > 0
0 < Delta_t_E, Delta_t_M_emit, Delta_t_M_rearm < infinity
0 < Delta_x_E <= X_max
0 < A_min <= A_max
1 <= P <= P_max = 64
```

Every bound is finite and validated. `P_max` is an architecture bound, not an
unbounded implementation hint.

## Persistent state and bounded bookkeeping

| Category | Canonical fields | Bound |
|---|---|---|
| Persistent dynamical state | signed `x`; local last-update timestamp; explicit `mode` | `-X_max <= x <= X_max`; monotonic finite logical time; four-value mode enum |
| Ordinary return state | scheduled event kind/time; ordinary episode ID; captured polarity; `m_peak` | one valid internal event; IDs and values bounded by the execution budget/configuration |
| Multi return state | multi episode ID; `m_phase` (`ARMED` or `REFRACTORY`); scheduled event kind/time; current sign at emission | one valid internal event; finite episode/lineage IDs |
| Causal bookkeeping | provenance ring, count, truncation flag, lineage ID | `0 <= count <= P <= 64` |
| Execution bookkeeping | event sequence, generation token, local counters | finite event budget; exhaustion terminates the run explicitly |

An independent persistent `y` is not part of the canonical state. A geometric
`(x,y)` trajectory remains legal as a visualization/reference projection.

## Event-driven accumulation

For an external arrival at local time `t_k`, first decay from the local
timestamp:

```text
x(t_k-) = x(t_(k-1)+) * exp(-lambda * (t_k - t_(k-1)))
x(t_k+) = clip[-X_max, X_max](x(t_k-) + v_ij(t_k))
```

The event is then recorded in the bounded provenance ring and the mode
transition is evaluated. There is no global neural timestep. Equal-time
external events retain the established deterministic sequence order.

## Explicit mode state machine

The canonical mode is one of:

| Mode | Entry condition | Valid internal event | Output rule |
|---|---|---|---|
| `N` | initial/reset or finite re-arm with `|x| <= theta_R` | none | no output; accumulate/leak |
| `S_PENDING` | `theta_E <= |x| < theta_M` after an external update or final M residual | `S_EMIT` | exactly one ordinary excursion if not promoted |
| `S_RETURN` | successful `S_EMIT` | `S_REARM` or none | no second ordinary excursion in this episode |
| `M_ACTIVE` | `|x| >= theta_M`, or promotion from S | `M_EMIT` when `ARMED`, `M_REARM` when `REFRACTORY` | repeated bounded M excursions, then at most one final S excursion |

Region membership alone is not the state machine. `mode`, pending event kind,
episode identity and generation are canonical bounded state.

### `N` transitions

On each ordered external update:

```text
|x| < theta_E                 -> remain N
theta_E <= |x| < theta_M     -> enter S_PENDING
|x| >= theta_M                -> enter M_ACTIVE, phase ARMED
```

`S_PENDING` allocation captures `ordinary_episode_id`, `lineage_id`,
`polarity = sign(x)`, initializes `m_peak = |x|`, and schedules `S_EMIT`.

### `S_PENDING` admission and promotion

Admission at logical time `t_a` schedules:

```text
S_EMIT at t_a + Delta_t_E
```

For each later external arrival, decay, accumulate, update provenance and:

```text
|x| < theta_M -> remain S_PENDING; m_peak <- max(m_peak, |x|)
|x| >= theta_M -> cancel S_EMIT and enter M_ACTIVE
```

Promotion preserves `lineage_id` and accumulated `x`/provenance, closes the
ordinary episode, allocates a `multi_episode_id`, sets phase `ARMED`, and
schedules `M_EMIT` at the promotion time plus `Delta_t_M_emit`. The canceled
ordinary excursion is not emitted.

### Ordinary emission and amplitude

When a valid `S_EMIT` executes, external arrivals at that timestamp have
already been processed. The neuron decays to the event time and updates
`m_peak`. If the mode is still `S_PENDING`, it emits exactly one digital event
with:

```text
A_exc = A_min + (A_max - A_min) *
        clip((m_peak - theta_E) / (theta_M - theta_E), 0, 1)
p_exc = captured_polarity * A_exc
```

The map is deterministic, finite, bounded, monotone and saturating. The event
receives a unique identity and the current lineage. The mode becomes
`S_RETURN`; the ordinary episode is marked emitted.

### `S_RETURN` and ordinary re-arm

At emission time, let `q = |x|`.

```text
q <= theta_R -> transition immediately to N and close the lineage
q > theta_R  -> schedule S_REARM at
                t_emit + ln(q / theta_R) / lambda
```

The analytic schedule is finite because `lambda > 0` and `theta_R > 0`.
It replaces an implicit timestep loop.

On an external arrival during `S_RETURN`, cancel the pending `S_REARM`
generation, decay, accumulate, update provenance, then:

```text
|x| < theta_R                 -> N; close the lineage
theta_R <= |x| < theta_M     -> remain S_RETURN; schedule new S_REARM
|x| >= theta_M                -> enter M_ACTIVE; schedule M_EMIT
```

No additional ordinary excursion is admitted while the same episode remains
in `S_RETURN`. At a valid `S_REARM`, decay to its timestamp; if
`|x| <= theta_R`, enter `N` and close the lineage. A new ordinary excursion
requires a later `N` admission.

## Multi-excursion state machine

`M_ACTIVE` uses a bounded hybrid generator rather than a continuously
simulated oscillator:

```text
M_ACTIVE / ARMED
    -> due M_EMIT
M_ACTIVE / REFRACTORY
    -> due M_REARM
```

The generator coordinates satisfy `h_min <= h <= h_max` and `h_L < h_H`;
they are not compared with `theta_hold`.

### M entry and emission

On M entry, phase is `ARMED` and one `M_EMIT` is scheduled at:

```text
t_entry + Delta_t_M_emit
```

When a valid `M_EMIT` executes, external events at the same timestamp have
already been processed. If local decay leaves `|x| <= theta_hold`, no M output
is emitted; transition to final `S_PENDING` when `|x| >= theta_E`, otherwise
to `N`.

Otherwise emit exactly one bounded M excursion:

```text
p_exc = sign(x_emit) * A_max
```

The sign is selected at the actual M emission transition. Then discharge:

```text
q_after = max(theta_hold, |x| - Delta_x_E)
x <- sign(x) * q_after
```

If `q_after <= theta_hold`, close the M episode and enter `S_PENDING` with
`m_peak = q_after`; this schedules the final ordinary excursion. Otherwise set
phase `REFRACTORY` and schedule `M_REARM` at:

```text
t_emit + Delta_t_M_rearm
```

### M re-arm and external input

At valid `M_REARM`, decay to its timestamp:

```text
|x| > theta_hold -> phase ARMED; schedule M_EMIT at
                    t_rearm + Delta_t_M_emit
|x| <= theta_hold and |x| >= theta_E -> enter S_PENDING
|x| < theta_E -> enter N and close the lineage
```

On every external arrival in `M_ACTIVE`, cancel the current valid internal
generation, decay, accumulate, clip, update provenance and re-evaluate sign
and magnitude:

```text
|x| <= theta_hold -> cancel M event; S_PENDING if |x| >= theta_E, else N
|x| > theta_hold  -> retain M_ACTIVE and reschedule:
                     M_EMIT if ARMED, M_REARM if REFRACTORY
```

Rescheduling uses the fixed delay from the arrival timestamp. Opposite-sign
input may reduce, cancel or reverse `x`; any later M emission uses the current
sign. No emitted excursion is retroactively changed.

## Finite-return proof

With no new input, every M emission decreases magnitude to:

```text
q_after = max(theta_hold, q_before - Delta_x_E)
```

For `q_0 > theta_hold`, the number of M emissions is bounded by:

```text
N_M <= ceil((q_0 - theta_hold) / Delta_x_E)
```

and is zero for `q_0 <= theta_hold`. Since
`theta_M <= q_0 <= X_max`, the bound covers `q_0 = theta_M`,
`q_0 = X_max`, negative states, clipping and zero-crossing prevention.
After the final M discharge, `q_after = theta_hold`, which lies in the
ordinary S region because `theta_E <= theta_hold`; therefore at most one final
S excursion follows. The S return reaches `N` at the finite analytic
`S_REARM` timestamp. Each cycle has positive finite delay, so no zero-time
emission loop exists.

External input can extend the episode, but every arrival consumes the existing
finite event budget and cannot create unbounded pending internal state.

## Internal event ordering, cancellation and bounds

At an identical logical timestamp, external incoming events for a destination
are processed in existing sequence order before that destination's due internal
event. Internal event sequence identities remain deterministic after external
events. Events at different timestamps retain timestamp ordering.

Every internal event record contains:

```text
neuron_id, episode_id, generation, kind, timestamp, sequence
```

Cancellation increments the bounded generation token and clears the pending
slot. A dequeued record is a deterministic no-op unless its episode, generation,
kind and timestamp match the current pending slot. Generation allocation is
limited by the declared execution event budget; exhaustion terminates the run
instead of wrapping or creating unbounded tombstones.

At most one valid internal event is outstanding per neuron. Superseded queue
records are bounded by the existing queue capacity and global event budget.

## Provenance, identity and predictive coding

Each contribution stores the minimum causal fields required by delayed credit:
event identity, timestamp and signed contribution. The ring capacity obeys
`1 <= P <= 64`. On overflow, evict the oldest contributor and set
`provenance_truncated = true`. Complete delayed-credit attribution is not
claimed after truncation; lineage remains bounded.

Each excursion/digital output has a unique non-negative identity/sequence,
source neuron, logical timestamp, signed payload, event type and bounded
lineage/episode ID. Multiple M excursions share an episode lineage but have
distinct event identities.

Accumulator evolution is local internal evidence. No downstream signal is
generated merely because `x` changes. Predictions intended for downstream use
are emitted through canonical excursions, and explicit prediction-error events
remain normal causally propagated TPCN events. No learning rule is added.

## Model-B source and compatibility

After migration:

```text
a_i := p_exc
```

where `p_exc` is the signed excursion payload. Model-B remains unchanged. The
former continuously recomputed `tanh(g_j * s_j)` value is an internal
compatibility/diagnostic value, not a second canonical outgoing stream.

Legacy continuous output remains only as an explicitly named, trace-labelled
compatibility mode. It is not a second production neuron type and cannot
appear in new canonical IR state without an explicit legacy label.

## IR and hardware boundary

Acceptance requires a future `TPCN-IR-2` schema for excursion neurons. IR-2
must represent the dynamics version, `x`, timestamp, mode, thresholds, return
timing, pending event generation/kind/time, amplitude parameters, M discharge,
provenance capacity/state/truncation, lineage and re-arm state. IR-1 readers
must reject excursion records rather than reconstructing them as `tanh`
neurons. IR-2 is not implemented by this ACP.

No canonical requirement names CUDA scheduling, FPGA clock cycles, FPGA
registers, FPAA component values, analog voltage or physical spike width.
Those remain backend contracts under ACP-0003.

## Deterministic fixture plan

The reference fixture configuration is the numeric configuration above. It
requires these expected observations:

1. `+0.4@0`, `+0.4@0.1`, `+0.4@0.2` produces one S excursion.
2. The same contributions at `0`, `5`, `10` produce no excursion.
3. `+1@0` enters `S_PENDING`; exact `theta_E` is inclusive.
4. `+3.99@0` produces exactly one ordinary excursion.
5. `+4@0` enters M; exact `theta_M` is inclusive.
6. `+8@0` produces finitely many bounded M excursions and one final S
   excursion, never a zero-time burst.
7. Mirrored positive/negative inputs produce mirrored polarity.
8. Input during `S_PENDING` below M updates `m_peak`; input at/above M
   cancels S emission and promotes to M.
9. Input during `S_RETURN` cancels/reschedules re-arm and can promote to M.
10. Input during M can reduce, reverse or extend the current signed state.
11. Same-timestamp external input precedes an internal event; promotion
    cancels the stale internal generation deterministically.
12. More than 16 retained contributors evicts oldest provenance and exposes
    `provenance_truncated`.
13. Recurrent execution terminates at the finite event budget; stale
    generations are no-ops.
14. Same seed/configuration reproduces traces, and batched/unbatched execution
    preserves the declared causal order without a neural timestep.

## E2/M canonical identity and provenance clarification

Ordinary and multi-excursion episode identities share one monotonic,
neuron-local episode identity counter/high-water mark. M admission allocates a
new `multi_episode_id` from that counter. When M enters its final residual
`S_PENDING`, the runtime allocates a new `ordinary_episode_id` from the same
counter. The two IDs therefore cannot collide and must not be reused:

```text
M_ACTIVE -> multi_episode_id = M
         -> final S_PENDING -> ordinary_episode_id = S
M != S
```

The bounded `lineage_id` remains continuous from M admission through every M
excursion, the final ordinary excursion and return to `N`. Each emitted M
excursion retains its immutable unique event identity, `multi_episode_id`,
lineage and timestamp. The final ordinary excursion has its own event
identity
and `ordinary_episode_id` while retaining the same lineage.

The active provenance ring represents current causal contributor state, not a
historical log of emitted excursions. On M-to-final-S transition, retained
active entries are re-owned to the new ordinary episode while preserving
causal event identity, timestamps, signed contributions, ordering, lineage
and `provenance_truncated`. Truncation is sticky across the transition. New
final-S contributions use the new ordinary episode ownership. Already-emitted
M output records are never rewritten. A direct M-to-N transition allocates no
ordinary episode and closes the M lineage.

## E2/M reset clarification

Reset at the declared local reset timestamp immediately sets `mode = N` and
`x = 0`, clears M phase, active episode IDs, lineage, ordinary polarity,
`m_peak`, the valid pending internal event, active provenance and truncation
state, residual/phase bookkeeping, character-local emissions/diagnostics and
the superseded E1 boundary state. Reset emits no M or S excursion.

Queued pre-reset `M_EMIT` and `M_REARM` records may remain in the bounded
queue, but are deterministic no-ops because the reset cleared the valid
pending slot and their episode/generation/kind/timestamp tuple cannot match
current state. Reset retains the monotonic output-event, shared episode,
lineage and automatic-input identity high-water counters. The generation token
may reset according to closed E1 semantics; stale safety also requires the
never-reused episode identity and current pending-slot equality.
