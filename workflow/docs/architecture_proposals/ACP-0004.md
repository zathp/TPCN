## Current invariant or soft constraint

The current canonical neuron is event-driven, locally timed, bounded, and
compatible with ACP-0002 N2 Model-B edge transfer. An edge still transfers

\[
z_{ij}=\tanh(w_{ij}a_i),\qquad
v_{ij}=d_{ij}z_{ij}+(1-d_{ij})r_{ij}
\]

after its existing finite positive propagation delay. This proposal does not
change that transfer, routing, fan-in/out limits, or event ordering.

This proposal changes canonical neuron output semantics and therefore requires
an independent architecture decision. A01-A15 remain unchanged. The proposal
is not authorization for ACP-0003 H2, a production backend, edge learning,
ACP-0002 N3, or a new Luna role.

## Observed problem

**OBSERVED:** the architecture needs a bounded local mechanism in which several
delayed signed contributions can alter one persistent state and be represented
downstream by fewer output emissions. Existing documentation uses “spike” both
for software events and for physical analog behavior, which conflates canonical
semantics with backend realization.

**HYPOTHESIZED:** a leaky accumulator with an explicit bounded return path can
compress ordinary contributions while reserving repeated emissions for an
explicit excessive-excitation regime. This hypothesis is architectural and has
not been implemented or measured at this revision.

## Proposed change

### Terminology and semantic boundary

The canonical object is an **excursion**, not a spike. An excursion is a
backend-neutral bounded output trajectory and logical emission. A digital
software reference represents one excursion with one or more TPCN events;
FPGA represents it with bounded digital event/pulse records; FPAA may
physically realize it with an analog spike or continuous analog excursion.
“Spike” is therefore reserved for FPAA/analog realization and compatibility
language, never used as a universal synonym for a canonical output.

Ordinary compression is called **single-excursion return**. Explicit repeated
output is called **multi-excursion return**, never canonical “multi-spike
mode.” Compression is \(N_{\rm input\ contributions}>N_{\rm excursions}\);
expansion is the opposite relation and is only permitted in the explicit
multi-excursion regime.

### Minimal canonical state

The persistent canonical dynamical state is a signed, bounded scalar \(x\)
with a local last-update timestamp. A bounded phase/mode enum and bounded
return bookkeeping are execution state, not a second unconstrained dynamical
coordinate. The output coordinate \(y\) is derived from the current bounded
return trajectory and need not be persistent. Thus `(x, y)` is a useful
geometric description, but only `x` is required as canonical persistent
excitation; retaining an independent persistent `y` is rejected as redundant
unless a later experiment supplies evidence that it preserves required
causal information.

Neutral state is `(x, y)=(0, 0)`, and with no input it is a stable attractor.
All state, phase, pending-emission, provenance and event-budget fields have
finite declared bounds.

For an arrival at local time \(t_k\), first apply local elapsed-time decay:

\[
x(t_k^-)=x(t_{k-1}^+)\exp[-\lambda(t_k-t_{k-1})].
\]

Then apply the delayed Model-B contribution sequentially:

\[
x(t_k^+)=\operatorname{clip}_{[-X_{\max},X_{\max}]}
          (x(t_k^-)+v_{ij}(t_k)).
\]

There is no global timestep. Equal-time arrivals use the established
deterministic sequence order, and the first arrival may change the mode before
the next is processed.

### Operating regions and ordinary return

Parameters satisfy \(0<\theta_E<\theta_M\le X_{\max}\), with signed threshold
tests based on \(|x|\):

* **N — neutral/subthreshold:** \(|x|<\theta_E\). No excursion is emitted;
  state accumulates and leaks.
* **S — single-excursion:** \(\theta_E\le |x|<\theta_M\). Exactly one bounded
  excursion is generated by one return trajectory.
* **M — multi-excursion:** \(|x|\ge\theta_M\). A bounded multi-excursion return
  is entered explicitly.

Moderate overshoot within S can change bounded excursion magnitude or duration
but cannot create repeated emissions. The ordinary trajectory must leave
neutral, follow a distinct return path rather than merely reverse the input
path, emit during return, and converge to neutral. A normalized reference
fixture may use a bounded \(s\in[0,1]\) lobe for geometry, but that
parameterization is an analytic fixture/approximation target, not canonical
equations.

The first canonical information carrier is amplitude only:

\[
A_{\rm exc}=f(|x_{\rm peak}|),\quad 0\le A_{\rm exc}\le A_{\max},
\]

where \(f\) is deterministic, bounded and monotone within the declared
parameter range. Timing and duration are not information channels in the
initial model beyond deterministic state-dependent trajectory completion.
This is the smallest falsifiable choice; later timing encodings require a new
proposal or an explicitly isolated experiment.

### Multi-excursion return and finite termination

Multi-excursion mode owns a bounded hysteretic generator \(h\), with
\(h_L<h_H\) and \(h_L\ge\theta_{\rm hold}\). A canonical excursion is allowed
when \(h\ge h_H\); another is forbidden until the generator re-arms at
\(h\le h_L\). Each emitted excursion discharges excessive signed state by a
bounded positive amount:

\[
x\leftarrow x-\operatorname{sgn}(x)\Delta x_E,
\qquad \Delta x_E>0,
\]

or by an equivalent monotone bounded relaxation. New input can increase
\(|x|\), update the current bounded amplitude, or prolong M; it is never
dropped. M exits when \(|x|\le\theta_{\rm hold}\), after which ordinary return
completes the path toward N.

The mandatory termination argument is a bounded ranking argument, not merely
simulation: with no new input, each permitted M excursion decreases
\(|x|\) by at least \(\Delta x_E\) until the hold boundary, and each
inter-excursion hysteresis cycle has bounded local state and finite duration.
Therefore at most
\(\lceil (|x_0|-\theta_{\rm hold})/\Delta x_E\rceil\) discharges occur before
ordinary return; the bounded ordinary return then reaches the neutral
attractor. Runtime event-budget and lineage bounds remain required for
recurrent topology.

### Signed behavior and timing

Positive and negative excursions are both supported. Thresholds are mirrored,
output polarity preserves `sign(x)`, and the reference fixture targets odd
symmetry \(F(-x,-y)=-F(x,y)\) where clipping and finite precision permit it.
Asymmetric thresholds are not part of the initial model.

An initiating input event, internal trajectory, logical emitted-event time and
physical FPAA peak/crossing time are distinct. The software/FPGA canonical
emission occurs at the deterministic logical return transition that crosses
the declared emission condition. Physical peak time is an implementation
observation only and must not redefine canonical event time.

### Existing activation and compatibility

The existing \(a_j=\tanh(g_js_j)\) path becomes a normalized internal
compatibility/diagnostic value, and may be used by the bounded amplitude map;
it is not an additional continuous outgoing activation. External canonical
output is excursion emission. A legacy continuous-output mode may remain only
as an explicitly named compatibility mode for old comparisons, with separate
traces and no claim of dual canonical semantics.

Unless an owner-approved migration experiment says otherwise, this proposal
migrates all reusable-core neurons to the excursion semantics rather than
creating a permanent specialized subtype. Legacy behavior remains available
only in legacy/compatibility paths.

### Predictive coding, credit and cheap/expensive work

Every arrival performs local decay, contribution accumulation, mode/boundary
checks, and bounded provenance update even when no excursion occurs. These are
cheap per-arrival operations and remain causally observable to local
prediction/error state. Excursion emission may trigger fan-out, prediction
generation, instrumentation, and eligibility/accounting work; those are
excursion-triggered expensive operations and must not hide required local
arrival bookkeeping.

Predictions and explicit prediction-error events remain governed by A06.
Compression may reduce temporal detail, so provenance retains a bounded ordered
set/ring of contributing event identities, timestamps, signed contributions,
and the resulting excursion identity. It need not retain unbounded history.
Predictions may be attached to excursions, while accumulator evolution remains
locally observable; multi-excursion outputs use the same interface with a
shared bounded provenance lineage. Delayed reward can therefore attribute one
excursion to several earlier contributions without introducing labels or
global state. No learning rule is implemented here.

### Backend mapping

ACP-0003 remains an interface/portability boundary:

| Canonical meaning | GPU/software reference | FPGA | FPAA |
|---|---|---|---|
| One excursion | one or more TPCN events | bounded digital event/pulse | analog spike/continuous excursion |
| Multi-excursion return | multiple TPCN events | repeated bounded digital emissions | multiple physical spikes/excursions |
| Timestamp | deterministic logical transition time | logical event/pulse time | physical peak/crossing is observational |

No backend implementation, approximation claim, calibration, or H2 work is
authorized by this draft.

### Compression metrics and fixtures

Canonical metrics count input contributions, accumulator updates, single
excursions, M entries, total excursions, and digital downstream events. The
primary metric is

\[
C_E=N_{\rm input\ contributions}/N_{\rm excursions}.
\]

GPU/FPGA may additionally report incoming/outgoing event ratio; FPAA may
report physical excursion statistics. None is a direct energy measurement.

Before implementation, the following deterministic fixtures are mandatory:
subthreshold no-emission; closely spaced temporal accumulation; widely spaced
leakage control; moderate input with one bounded excursion; extreme input with
multiple bounded excursions; finite return to neutral; signed mirror;
equal-time sequential arrivals; state-bound recurrence; and compression versus
explicit multi-excursion expansion. Each fixture declares time units,
thresholds, bounds, sequence priorities, and expected trace.

## Why implementation alone cannot solve it

Choosing an accumulator, excursion vocabulary, timing boundary, migration
model, and backend mapping changes the canonical neuron contract. A local code
change cannot decide whether `y` is canonical state, whether repeated output
is permitted, or whether physical spike timing defines digital semantics
without creating incompatible interpretations across ACP-0002 and ACP-0003.

## Expected benefits

* Compresses multiple delayed signed inputs without erasing causal state.
* Provides a bounded, analytically terminating path for excessive excitation.
* Separates canonical excursion semantics from software, FPGA and FPAA terms.
* Preserves event-driven timing, signed polarity, local prediction and delayed
  credit compatibility.
* Makes output count, state bounds and backend observations measurable.

## Expected disadvantages and risks

* Compression can discard fine temporal detail; bounded provenance and
  prediction interfaces must make the loss explicit.
* Threshold, decay, discharge and hysteresis parameters add configuration
  surface and may create mode-boundary sensitivity.
* A scalar accumulator may be insufficient for future trajectory-dependent
  learning; evidence must precede adding persistent dimensions.
* Legacy continuous traces will not be directly comparable without an explicit
  compatibility mode.

## Hardware implications

The state, timestamp decay, clipping, thresholds, hysteresis, discharge,
finite event budget and provenance bounds must be realizable in software,
FPGA/VHDL, FPAA and hybrid designs. Hardware clocks may schedule work but
cannot become neural time. FPGA uses bounded fixed/declared precision and
digital pulse records. FPAA may approximate the return trajectory with analog
state and physical spikes, but its peak timing is not canonical. Connectivity,
fan-in/out, routing, queue and energy metering remain finite and are not
changed by this proposal.

## Learning and energy implications

The proposal preserves local predictive coding, explicit error events and
delayed credit. Provenance is bounded and causal; labels, future inputs and
global evaluation state remain outside the neuron. Per-arrival decay and
accumulation are local resource costs. Emission-triggered fan-out and
prediction/eligibility work are additional costs. Compression metrics and
activity proxies are not physical energy measurements, and A10 continues to
favor useful expensive computation over inactivity.

## Compatibility and migration

ACP-0002 Model-B edge transfer, delay, event ordering and topology interfaces
remain unchanged. ACP-0003 H1/IR-1 remains canonical configuration plus
transferable initial/reference state; it must gain explicit neuron schema
support before any implementation, not through silent reconstruction.
Existing continuous-output traces are legacy comparisons only. A migration
must define versioned state serialization, reset behavior, parameter bounds,
trace labels, and deterministic replay fixtures before changing the reusable
core.

## Required experiments and acceptance criteria

No implementation or experiment is authorized by this draft. If accepted,
the next bounded implementation must provide a hardware-neutral reference
with deterministic seeds and declared time units, and separately verify:

1. all fixtures above, including equal-time order sensitivity;
2. state, phase, provenance, queue, lineage and event-budget bounds;
3. analytic finite-return bound against trace measurements;
4. odd signed behavior and polarity preservation;
5. \(C_E\), single/multi counts, and bounded amplitude;
6. new-input behavior during both return modes;
7. prediction/error and delayed-credit provenance compatibility;
8. batched/unbatched equivalence without a neural global timestep;
9. legacy compatibility traces are explicitly separated;
10. no labels/future data/global orchestration enter core state.

Acceptance requires independent review of the reference implementation and
fixtures. GPU, FPGA, FPAA, H2, calibration and hardware-equivalence claims
remain not applicable until separately authorized.
