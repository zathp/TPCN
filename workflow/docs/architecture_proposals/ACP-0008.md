## Current invariant or soft constraint

ACP-0004 gives each EXCURSION_V1 neuron one signed scalar `x` with a single decay rate `lambda` (`x(t+dt) = x(t)exp(-lambda dt)`, `x+ = clip(x + v)`), emitting only when `|x| >= theta_E`. A02 permits intrinsic temporal state; A08 requires bounded dynamics. This ACP adds an optional second intrinsic state. It changes neuron semantics only when explicitly enabled, so it is an architecture change (new persistent state) and not an implementation detail.

## Observed problem

Luna-37 (reviewed `NOT SUPPORTED IN THIS SETUP`, 960 executions, `eligibility_capacity=1024`) found valid routing (1715 transfers per edge condition, depth 1) but zero destination canonical emissions. Maximum post-transfer destination state was 0.6855 (`w=1`) and 0.9327 (`w=2`), below `theta_E=1`. Routed arrivals were at least about 12.9 time units apart with `lambda=1`, so pre-arrival state was at most about 1.6e-6 and nothing accumulated. Observation: sub-threshold excitation plus fast decay between sparse arrivals gives no emission. Hypothesis (not yet tested): a distinct slower state can retain temporally related evidence that the fast state discards.

The weight sweep is explicitly rejected: raising `w` from 1 to 2 changed neither the outcome class nor the mechanism, and a larger single transfer is not temporal integration.

## Proposed change

All of the following apply only when `E1Config.integration` is an `IntegrationConfig`; the default `None` is bit-identical to the baseline.

### State separation

| Role | Symbol | Meaning | Bound |
|---|---|---|---|
| Fast/output state | `x` | existing ACP-0004 state, decay `lambda` | `[-X_max, X_max]` |
| Integration state | `z` | slower local evidence store; not an emission and not visible to routing | `[-Z_max, Z_max]` |
| Canonical emission | `ExcursionEmission` | existing production event, produced only by the existing `S_EMIT`/M paths | unchanged |

### Parameters (`IntegrationConfig`)

| Parameter | Predeclared value | Meaning |
|---|---|---|
| `decay_rate_z` (`lambda_z`) | `0.1` | slow decay, `tau_z = 10 = 10 tau_fast`; must satisfy `lambda_z < lambda` |
| `input_gain` (`kappa`) | `1.0` | fraction of a sub-threshold input stored in `z` |
| `discharge_quantum` (`theta_Z`) | `1.0` | integration threshold and the charge moved per discharge |
| `z_max` (`Z_max`) | `4.0` | hard bound on `|z|` |

Validation: all finite and positive; `lambda_z < lambda`; `theta_Z >= theta_E`; `theta_E + theta_Z < theta_M`; `theta_Z <= Z_max`. These values are normalized unit-fixture values, not calibrated to any task stream. `tau_z` is an order of magnitude longer than `tau_fast` so the horizon is a testable ratio; it was not derived from the Luna-37 gap of 12.9.

### Equations (event-driven; elapsed local time only)

At every processed event with elapsed `dt` since this neuron's last update:

```text
x <- clip_Xmax( x * exp(-lambda   * dt) )
z <- z * exp(-lambda_z * dt)                       # |z| only shrinks
```

At an external input `v` (existing update `x <- clip(x + v)` first), if the neuron is in mode `N` and `|x| < theta_E` after that update (the input did not itself admit an excursion):

```text
z <- clip_Zmax( z + kappa * v )                      # integrate
if |z| >= theta_Z and x * z >= 0:                    # discharge condition
    s <- sign(z)
    z <- z - s * theta_Z                             # subtractive discharge
    x <- x + s * theta_Z                             # moves into the fast path
    # the existing N-mode admission then sees |x| in [theta_Z, theta_Z + theta_E)
```

Otherwise `z` is only decayed. Inputs in modes other than `N`, and inputs that themselves cross `theta_E`, do not add to `z` (no double counting of evidence that is already expressed). If the discharge condition's sign test fails, discharge is deferred (`z` retained and decaying); no emission is forced.

### Emission, compression and post-emission rule

Emission is not new: after discharge `x >= theta_Z >= theta_E` and `x < theta_E + theta_Z < theta_M`, so the existing ordinary path (`S_PENDING` then `S_EMIT` after `emission_delay > 0`) produces one canonical excursion with the unchanged amplitude formula and event identity. Compression: several sub-threshold inputs raise `z`; one discharge converts exactly `theta_Z` of stored evidence into one emission. Post-emission rule: **subtractive, partial retention**: `z` keeps `|z| - theta_Z`, which can contribute to a later emission only through further external inputs and decays at `lambda_z`; `x` follows the existing `S_RETURN` rule. Larger accumulated `z` leaves more residual evidence. Output amplitude stays variable by the existing `m_peak` rule. A strong isolated input (`|x| >= theta_E`) behaves exactly as in the legacy neuron and does not touch `z`.

### Configurable canonical emission threshold (owner amendment 2026-10-05)

`theta_E` is an explicit per-neuron configuration parameter, not an architectural constant. It is already exposed as `E1Config.theta_e` (alias `theta_E`) and serialized by IR-2 (`theta_e`); Luna-38 must preserve that boundary and not hard-code `1`.

| Property | Specification |
|---|---|
| Meaning | state magnitude at which the neuron admits a canonical emission (`\|x\| >= theta_E` in mode `N`) |
| Default | `1.0` (legacy behavior, unchanged) |
| Valid range | finite, strictly positive, and `theta_R < theta_E <= theta_hold < theta_M <= X_max` (existing validation, unchanged) |
| Per-neuron | yes: each neuron's `E1Config` may differ; no global threshold |
| Runtime change | **no**: fixed for an execution; a config is frozen. Adaptive/learned/homeostatic thresholds are future work needing their own contracts, but nothing here forbids a later mutable-threshold API (the value is read only through `config.theta_e`, never cached as a constant) |
| Serialization | IR-2 already carries `theta_e`; integration-enabled neurons are rejected by IR-2/TPCV-2 so nothing is silently dropped |
| Replay | the threshold is part of the config; identical config + stream gives identical results; a different threshold is a different configuration, never a replay |

Invariant: **temporal integration determines how evidence accumulates; the activation threshold determines how much accumulated state is required before canonical emission.** Neither substitutes for the other. In the model, `z` accumulates evidence irrespective of `theta_E` except for the single routing test "does this input itself cross `theta_E`" (which decides whether the input is expressed directly or stored); the discharge quantum `theta_Z` is the integration-state threshold and has its own dynamical role (the stored-evidence amount converted per emission). No `theta_I` is introduced: `theta_Z` already is that parameter, and adding another would have no distinct role. The constraints `theta_Z >= theta_E` and `theta_E + theta_Z < theta_M` are consistency conditions guaranteeing a discharge lands in the ordinary-emission band, not compensation; changing `theta_E` therefore requires a *predeclared* compatible `theta_Z`, never an automatic adjustment.

Independently configurable: `decay_rate` (fast), `decay_rate_z`, `theta_E`, `theta_Z`, the discharge rule (fixed subtractive in Luna-38), and the edge weight (outside the neuron). Luna-38 uses the default `theta_E=1` for fixtures A–I and only three predeclared alternative values for the validation fixtures J–L; no threshold sweep and no tuning against Luna-37 data.

### Temporal selectivity

Because `z` decays at `lambda_z`, evidence outside roughly `tau_z` is discarded: the stored fraction of an input after a gap `g` is `exp(-lambda_z g)`. Falsifiable prediction (see fixtures in the Luna-38 contract): four inputs of `0.4` spaced 2 units give a discharge at the fourth input; the same inputs spaced 10 or 40 units do not.

### Boundedness and no free emission

`|z| <= Z_max` by clipping and decay. Each discharge consumes `theta_Z` of `|z|`, `|z|` increases only by `kappa|v| ` at external inputs, so the number of discharges is at most `(|z_0| + kappa sum|v|) / theta_Z`; at most one discharge occurs per external event; discharge creates no internal event at the current time (the existing `emission_delay > 0` separates it from the cause). No unbounded same-time loop and no spontaneous excitation: with no input, `x, z -> 0` (neutral attractor). Discharge cannot enter the M regime by itself because `theta_E + theta_Z < theta_M`.

### Threshold-oscillator staging decision

The E2 multi-excursion `M` regime (`|x| >= theta_M`, `M_ACTIVE`, bounded re-arm, finite-return proof in ACP-0004) already is the bounded extreme-excitation oscillator return path. It is unchanged and `z` does not feed it. A separate `z`-driven multi-spike discharge is **staged out of Luna-38**: a clean causal test of accumulation and single-spike compression must not be confounded with a second new discharge regime. Extreme `z` simply yields repeated single discharges, one per later external event, each consuming `theta_Z`. A `z`-driven oscillator needs a later Luna and its own review.

### Interfaces whose assumptions could be affected

`neuron.state` still returns `x` only. `neuron_to_ir2`/`neuron_to_ir2_e2` and `ExcursionNeuronRecord.from_neuron` (TPCV-2) assume the neuron state is the scalar `x`; Luna-38 must make them reject integration-enabled neurons rather than silently drop `z`. Routing, predictions, observations, prediction-error, reward/eligibility, structural candidate evidence and event identity are not modified (provenance of contributing inputs is retained by the existing unassigned-provenance mechanism). Energy/bit-change accounting is not extended to `z` (known unknown).

## Why implementation alone cannot solve it

Slowing `lambda` globally would destroy the fast response that Luna-37 shows is useful; raising `w` or lowering thresholds is excluded by the owner. A second timescale is new persistent state and a new emission-causing path, which is a change to the neuron contract.

## Expected benefits

Allows temporally separated sub-threshold events to be compressed into one canonical emission with an explicit, testable horizon.

## Expected disadvantages and risks

Extra state (hardware register and decay constant); an additional parameter set; possible over-integration; discarded input in non-`N` modes; no energy accounting for `z`; the 12.9-unit Luna-37 gaps still decay by `exp(-1.29) = 0.275` per gap, so this unit-normalized setting is not expected to rescue those streams without a later, separately justified task-scale calibration.

## Hardware implications

One extra signed bounded register, one multiply-decay per processed event with elapsed time (the same primitive as `x`), one compare and one subtract for discharge. No global clock, no new queue entries. Fixed-point precision and decay quantization are not claimed equivalent.

## Learning and energy implications

Local only: `z` depends only on this neuron's inputs and elapsed time. Prediction/error, reward and eligibility semantics are untouched. Energy accounting is not extended; activity proxies remain uncalibrated.

## Compatibility and migration

Optional field `integration: IntegrationConfig | None = None` appended to `E1Config`; default behavior and all 952 existing passing tests unchanged; IR-2/TPCV-2 reject integration-enabled neurons. Rollback is trivial because the field is opt-in.

## Required experiments and acceptance criteria

Defined in `.github/agents/luna-38.agent.md`: unit fixtures A–D plus bounded-compression, sign, replay, legacy bit-identity and boundedness checks. No task-stream experiment and no ACP-0007 candidate-formation or efficacy claim is authorized.

## Rollback plan

Known-good: `b0363ee035b1ffc60bd00d46277a0c789f11e570` (or any configuration with `integration=None`). Remove the optional field and guards; no artifact migration.
