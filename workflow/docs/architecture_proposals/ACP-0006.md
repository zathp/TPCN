## Current invariant or soft constraint

This accepted ACP does not amend A01-A15 or change the closed ACP-0002 N2,
ACP-0004 E1/E2, or ACP-0005/TPCN-IR-2 semantics. It defines the
network-level contract for composing those components in the streaming
predictive-coding experiment path.

The relevant accepted semantics are:

- A01-A03: events are causally processed at local logical timestamps with
  finite positive edge delays; no global neural timestep is required.
- A04/A08: nodes, fan-in/out, routing, queues, paths and execution are bounded.
- A06/A07/A11: predictions, explicit prediction errors, local learning and
  delayed credit remain causal and bounded; labels and future inputs do not
  become hidden neural inputs.
- A09/A10: local activity-cost proxies are distinct from calibrated physical
  energy, and useful computation is not suppressed merely to minimize energy.
- A14: bounded local structural adaptation remains supported but may be off
  for the first integration.
- A15: the software reference remains hardware-neutral; no backend equivalence
  follows from this proposal.
- ACP-0002 N2: static Model-B remains
  `z_ij = tanh(w_ij * a_i)` and
  `v_ij = d_ij * z_ij + (1 - d_ij) * r_ij`.
- ACP-0004: the canonical output is an `ExcursionEmission`; accumulator-state
  changes alone do not emit; after migration `a_i := p_exc`; legacy continuous
  output is explicitly labelled compatibility behavior, never a second
  canonical stream.
- ACP-0005: IR-2 is a versioned transferable neuron/reference state, not a
  complete live-network checkpoint.

## Observed problem

**OBSERVED:** `_ComputationalNetwork` currently constructs `TPCNNeuron`
instances. For each input point it creates a fresh queue, calls
`execute_bounded()` to drain the queue, uses each returned scalar activation
for downstream routing, and derives prediction, eligibility, energy and
readout values from activation magnitudes. This is a scalar-per-event
execution path.

**OBSERVED:** `SingleExcursionNeuron` and `MultiExcursionNeuron` instead accept
external or internal events, update bounded local state and may return no
output or one `ExcursionEmission`. The E2 runtime schedules future internal
events in an `EventQueue`; its output identity and lineage are distinct from
queue sequence and routing path. `BoundedTopology.route()` applies the
unchanged Model-B transfer to numeric `signal` and `excursion` events and
preserves their event identity and lineage.

**OBSERVED:** A fresh per-point queue can process an internal event at time
`1.0` immediately after input at `0.0`, before an as-yet-unadmitted streaming
input at `0.5`. That violates causal stream ordering. `execute_bounded()`
drains all queued timestamps up to completion/budget; it does not accept an
external-input watermark.

**OBSERVED:** `LocalPredictor.create_prediction_from_neuron()` is typed to
`TPCNNeuron`. `EligibilityActivity`, `PredictionError`, the streaming
classifier, and the energy meter have numeric scalar/event interfaces, but
there is no integrated adapter specifying when an excursion counts as
prediction, eligible activity, readout, or energy activity.

**OBSERVED:** IR-2 represents each neuron's pending internal event and local
state, but excludes arbitrary shared network queues, predictor state,
eligibility/reward state, classifier state and other in-flight scheduler state.

**INFERRED:** E1/E2 and IR-2 closures do not by themselves specify how the
actual predictive-coding experiment path constructs the model, schedules
future work against an incrementally revealed input stream, or consumes an
excursion across routing, prediction, error, credit and readout boundaries.

## Accepted integration contract

The following 17 integration rules form the accepted contract. They apply to
the integrated production path after migration; execution is authorized only
within the separately bounded Luna-22 assignment.

### 1. Canonical production neuron model and model selection

After implementation and migration, an ordinary TPCN production experiment
constructs a **network-wide `EXCURSION_V1` model backed by the E2-capable
`MultiExcursionNeuron` runtime**. E2 already includes the ordinary E1 modes;
the E1-only `SingleExcursionNeuron` remains a reference/control implementation
and is not a second selectable production model.

Model selection is an explicit network-construction/experiment configuration,
not inferred from a record, node, observed state or failed conversion. One
network instance uses exactly one model. A mixed `TANH_LEGACY` /
`EXCURSION_V1` network is rejected for the first integration.

`TANH_LEGACY` remains available only through an explicitly named experiment
compatibility/replay configuration and explicit IR dynamics tags where
supported. It is not the normal post-migration default, is not silently
selected when excursion state is absent or unsupported, and must not create a
second continuous output stream in an excursion network. Once this ACP is
accepted, the integrated experiment default is `EXCURSION_V1`; pre-migration
commits remain reproducible from their own revisions.

### 2. Causal network event loop and 12. Queue lifetime

The first integrated runtime owns one finite event queue per character. It is
created at START_CHARACTER, retained across every point submission and
internal/routed event, settled at END_CHARACTER, and destroyed after the
character boundary. It is not recreated per point or reused by a later
character.

The input stream is admitted incrementally; unseen future points are never
pre-enqueued or inspected. Before admitting an external event at timestamp
`t`, process queued network/internal work with timestamp **strictly less**
than `t`. Then admit all external events already available for timestamp `t`
and process queued events through `t`. This preserves the queue's
destination-local external-before-internal rule at equal timestamps. A stream
event that arrives after its timestamp has been committed is a late event and
must fail explicitly; it is not reordered silently.

For multiple causally available external events at the same exact timestamp,
the stream adapter submits the available same-time set before draining events
at that timestamp. Queue insertion sequence provides deterministic order among
otherwise equal eligible events. This is event-time grouping only, not a
simulation tick. No fixed-duration polling, all-neuron update or wall-clock
wait is introduced.

The character queue, all queued events and execution counters are bounded.
Queue overflow, invalid late input and event-budget exhaustion are explicit
failures/termination states, never silent event drops. Model-B edge delays
remain finite and positive. A run's event budget counts admitted external,
internal, routed and prediction-error events processed by the integrated
network; each neuron retains its own accepted ACP-0004 event budget.

For example, after input at `t=0` schedules `M_EMIT @ t=2`, input at `t=1`
must be admitted and processed before `M_EMIT @ t=2`. At END, the separate
bounded settling rule below applies.

### 3. Internal-event causal and routing ownership

Queue sequence, route path, causal root identity, excursion event identity,
episode identity and lineage identity are distinct fields with distinct
purposes. A network-owned bounded sidecar associates each queued event with
its causal root ID set, current route depth and route path; it is keyed by the
queue sequence and exists only for that character.

An external input begins a causal root with deterministic input identity. A
routed event inherits its parent's root IDs, appends its destination to that
event's route path and increments route depth exactly once per traversed edge.
Within one routed-event path, a node may not be visited twice and route depth
is capped by the finite network node count. Edge delay and topology capacity
remain authoritative.

When the neuron schedules valid internal work, the scheduler associates the
pending token `(neuron_id, episode_id, generation, kind, timestamp,
queue_sequence)` with the root IDs of the causal event that created or most
recently changed that pending work. If further external/routed contributions
arrive while the same episode is active, their root IDs are merged into the
pending work's bounded root set. The bound is the neuron provenance capacity;
truncation is sticky and reported, consistent with ACP-0004's provenance
limit. Cancellation removes the matching sidecar. A valid internal event
inherits that causal-root set; it is never an unrelated external root.

Each actual `ExcursionEmission` receives its already-defined unique
`event_id`, episode and `lineage_id`. It begins a **new per-emission route
path** at its source with depth zero, and retains the inherited causal roots
and neuron lineage as separate metadata. This prevents an internal emission
from inheriting sibling-emission path entries as if they were its own path,
while retaining causal ancestry. Each routed edge copy preserves the emission
identity and lineage. The finite per-character event budget also bounds
repeated causal excursions through recurrent topology.

The sidecar is runtime scheduler state and is not represented by IR-2.
Network reset clears it with the queue. Active-network reconstruction is
therefore outside this proposal's IR-2 boundary.

### 4. Canonical outgoing routing

For any processed external or internal neuron event:

```text
if processing returns no ExcursionEmission:
    emit no outgoing neuron signal and route nothing

if processing returns ExcursionEmission e:
    a_i := e.payload
    route exactly e as one canonical excursion through the
    existing bounded Model-B topology
```

No scalar state, activation, accumulator value, diagnostic compatibility
value or synthetic zero event may be routed as an additional output. The
unchanged Model-B calculation is:

```text
z_ij = tanh(w_ij * e.payload)
v_ij = d_ij * z_ij + (1 - d_ij) * r_ij
arrival_time = e.timestamp + tau_ij
```

The source event's identity, lineage and logical emission timestamp are
preserved on every routed edge record; the receiving record has the edge
arrival timestamp and a fresh queue sequence. The topology continues to apply
positive finite delay and deterministic equal-time event ordering.

### 5. Prediction creation boundary

Prediction is output-event based, never a read of hidden excursion state or a
continuous activation. Each explicitly configured predictor-source neuron
creates exactly one prediction for each `ExcursionEmission` it produces;
non-predictor neurons create none. The predictor is network-local and bounded
by its declared maximum outstanding predictions.

For emission `e`, `predicted_value = e.payload` and
`prediction_timestamp = e.timestamp`. The target key names the configured
numeric external input port and payload schema, not a class, label, future
point or global statistic. For the first integration it means the **next
numeric contribution admitted at that same causal input port** (the scalar
already supplied as the current input event payload; no whole-character
preprocessing is added).

When the next external input actually arrives at the port, its current payload
and timestamp form the observation. Before processing same-time internal
events, the observation is matched against outstanding predictions. At an
equal timestamp, deterministic queue/input ordering decides event order;
only a causally later input event can resolve a prediction. No future input is
read early.

When multiple M excursions occur in one neuron-local lineage, every
configured-source emission creates a separate prediction ID. Outstanding
capacity remains finite; observations match one eligible prediction per key
using the existing oldest-first deterministic rule. The finite configured
prediction expiry applies; expiry is advanced only by a later local
observation or the declared character settling boundary. Capacity exhaustion
and expiration remain observable outcomes. This does not change the existing
prediction-matching or error arithmetic.

### 6. Prediction-error event boundary

A later matched input observation produces the existing `PredictionError`
fields: `prediction_id`, `predictor_id`, `target_key`, `predicted_value`,
`observed_value`, signed error, prediction timestamp, observation timestamp
and observation source. It is wrapped in an explicit
`PREDICTION_ERROR_EVENT` at the observation timestamp, with event identity
equal to the matched prediction ID and the causally observed excursion
lineage retained where available.

The error event is first dispatched locally through the same character queue
to the predictor's error/eligibility consumer. It is then propagated as an
opaque prediction-error event over the existing directed topology, using
finite edge delays but not Model-B's numeric signal transfer. At each
destination, the network event adapter—not the neuron—may deliver it to a
local error consumer and forwards it over that node's outgoing edges. A
bounded per-character duplicate/delivery guard keyed by prediction ID and
destination ensures one credit application per destination even when paths
converge; deterministic queue order selects the first arrival. The full
`PredictionError` payload remains metadata and is never passed directly to
`MultiExcursionNeuron.receive_event()`. The error does not reveal a label or a
future observation. Existing `PredictionError` semantics and signed error
calculation are unchanged.

### 7. Eligibility boundary

Eligibility is recorded only for a canonical excursion, never for silent
accumulator changes. For each eligible local ledger, the event-time activity
is `magnitude = abs(e.payload)`, `trace_id` is the stable namespaced canonical
excursion `event_id`, and `prediction_id` is the prediction ID created from
that same emission when the source is a configured predictor. The record's
timestamp is the emission timestamp. The existing ledger capacity, decay,
trace limits, delayed error matching and reward-message idempotency remain
unchanged.

An emitted event may create an eligibility trace even when it has no
configured predictor ID; in that case later credit must address its trace ID,
not an inferred prediction. No trace is recorded for un-emitted state change.
The existing outer reward remains a single `RewardSignal` attribution: it
targets the first readout-source excursion trace in deterministic event order.
If the character had no such emission, the reward is explicitly unmatched;
credit is not silently spread across all excursions. Reward value, stable
message identity, bounded idempotency window and ledger update formula are
unchanged. Character-local traces are consumed by their applicable
reward/error events before reset; unmatched and expired credit remains
explicitly classified.

### 8-9. Readout, feature aggregation and external learning

The external streaming classifier receives each actual canonical excursion
produced by configured readout-source neurons as one numeric
`ACTIVITY_EVENT` with the signed `e.payload` and `e.timestamp`. It receives
no record when a neuron is silent; silence contributes **no activity
evidence**, not a fabricated zero-valued event. The existing classifier's
deterministic zero-evidence result remains visible and must be reported with
zero activity rather than mistaken for a neuron emission. Multiple M
excursions are separate ordered activity events.

For the outer readout/prototype-learning path, the first integration retains
external learning but adapts its scalar feature to bounded excursion
statistics: accumulate the signed payload and count of actual readout
excursions, both capped by the per-character event budget, then use the
arithmetic mean when count is nonzero and exactly `0.0` when count is zero.
The classifier and this accumulator are outside the reusable neural core.
They receive data only as each event occurs; finalization happens after
settling. Training labels are used only after the label-free readout result to
compute outer reward and update the external class prototype. They never
enter event payloads, neuron state, routing, predictors or eligibility before
that boundary.

No future-point preprocessing, unrestricted neural learning or new readout
algorithm is authorized. Existing prototype/readout learning is retained as
an explicitly external learner, with its input statistic changed from
continuous activation aggregates to the bounded excursion statistic above.

### 10. END_CHARACTER finite settling

After the last external point at `t_last`, settle the character queue in
timestamp order through the inclusive logical deadline
`t_last + settling_horizon`, subject to both the configured finite settling
event budget and the queue's finite capacity. `settling_horizon` is a declared
finite duration in logical time units; it is not a tick, polling interval or
wall-clock wait. Due events created by internal emissions and finite edge
delays may be processed until the queue is empty through that deadline.

`END_CHARACTER` is delivered to the external classifier only after all queued
events at or before the deadline have been processed or the event budget has
explicitly terminated execution. Events beyond the deadline are discarded at
the character boundary with an explicit count and `settling_horizon` status.
If the event budget is exhausted with due work pending, the classifier may
return its deterministic partial result, but the run is marked
`budget_exhausted` / incomplete and cannot satisfy the integration gate as a
completed run. No pending work is silently called settled. Expired predictions,
pending error delivery, unmatched predictions and readout coverage are
reported at the boundary. There is no wall-clock sleep or global neuron
advance.

### 11. Character and experiment reset

Character reset occurs only after settling status, readout, and any
label-authorized outer reward have been recorded. It destroys the character
queue and route-context sidecar; counts and reports any intentionally
discarded beyond-deadline events; calls `MultiExcursionNeuron.reset()` at the
declared new character-local time for every neuron; and clears all
character-local pending predictor records, eligibility traces/reward IDs,
error-delivery deduplication and classifier state. No prior-character event
or error can enter the next character.

Neuron output-event, episode, lineage and automatic-input identity high-water
counters survive this reset, as specified by ACP-0004. Predictor sequence
identity is also monotonic within an experiment/model instance. Reward and
error message identities are namespaced by that instance and character and
remain retry-idempotent within their bounded ledger scope. Persistent topology,
its static Model-B parameters, and outer learned class prototypes survive
character reset.

Experiment/model reset destroys the complete network instance, topology,
predictors, ledgers, readout prototypes and counters. A new run namespace
prevents identity collisions across retained diagnostic artifacts; the same
seed/configuration/input yields deterministic replay. No state is implicitly
carried between train, validation and test partitions.

### 12. Queue lifetime

The single character-scoped bounded queue defined above is the sole
first-integration network scheduler. It is created at START_CHARACTER, is
preserved across point submissions and future scheduled work, is settled once
at END_CHARACTER, and is destroyed after reset. It does not live across
characters or experiment instances. The implementation may use an equivalent
bounded representation only if the same admission watermark, event ordering,
reset, capacity and replay semantics are preserved.

### 13. IR-2 reconstruction/startup boundary

IR-2 remains a per-neuron transferable reference format, not a network
checkpoint. First-integration startup may reconstruct a uniformly
`EXCURSION_V1` network only at a declared quiescent initialization boundary:
the shared queue and sidecar are empty; each neuron is in `N` with no valid
pending internal event or active episode; and predictors, eligibility,
reward-idempotency and readout state are fresh. Serialized neuron identity
high-water counters and explicitly approved static neuron configuration may
be restored. Nonzero residual state or unassigned provenance from a prior
character is rejected at this boundary. No in-flight edge events are inferred
or fabricated.

`TANH_LEGACY` reconstruction is through its explicit legacy adapter and
uniform legacy experiment selection only. Mixed dynamics records are rejected
by the first-integration network builder. Active/pending neuron IR-2 reference
round trips remain supported by the standalone E2 adapter but cannot be
inserted into an integrated live network without a complete scheduler-state
representation. A future full live-network checkpoint, including shared
queue, route contexts, predictors, ledgers, reward IDs and classifier state,
requires a separately reviewed versioned format; IR-2 is not extended here.

### 14. Legacy compatibility and 15. E1/E2 production roles

After migration, normal experiments use the network-wide
`EXCURSION_V1`/E2-capable model. E1 remains the closed single-excursion
reference/control, not a selectable production network mode.

`TANH_LEGACY` is an explicit, network-wide compatibility/replay control. It
uses the historical scalar output path only when requested and must label
configuration and traces accordingly. Compatibility is not the implicit
fallback for missing, invalid or unsupported excursion state. IR-1 remains
legacy-only and rejects excursion state. Historical commits remain the
strongest bit-for-bit reproduction path; no numeric or accuracy equality is
required between legacy and excursion models.

### 16. Energy accounting

The integrated energy value remains an `activity-cost-proxy`, not calibrated
joules. The proposed minimum local account is one proxy unit per processed
external, routed, internal or prediction-error event; one additional
`abs(e.payload)` proxy amount per canonical excursion emitted; one unit per
static Model-B edge transfer; and the existing declared local error-cost
formula for a matched prediction error. All counters and totals remain finite
and bounded. A silent event still incurs its event-processing proxy cost but
creates no emitted-signal or readout activity. Existing reward/utility rules
are unchanged. Legacy and excursion controls report their event and amplitude
components separately; comparisons are not physical energy-equivalence
claims.

### 17. Structural-plasticity boundary

The first integrated path uses fixed topology and must run with structural
plasticity disabled. No N3 edge adaptation or new candidate-evidence semantics
are activated by integration. Static topology and its bounded Model-B
parameters remain available. Structural adaptation may be reintroduced only
under its existing local evidence contract and separate authorization; this
proposal does not redesign it.

## Required controls for a future integration

The implementation must compare:

1. an explicitly selected `TANH_LEGACY` compatibility/control run; and
2. an `EXCURSION_V1` integrated run.

Both use the same external ordered input stream, fixed topology and Model-B
parameters, queue and event budgets, causal timestamps, reset boundaries,
label boundary, predictor target schema and readout protocol. This is a
semantic integration comparison, not a requirement for matching numeric
outputs or accuracy. Labels remain external in both conditions. The
compatibility configuration must not activate silently.

The mandatory causal counterexample is:

```text
external input @ t0 schedules valid E2 internal event @ t2
next external input @ t1, where t0 < t1 < t2
```

The observed processing order must be `t0`, `t1`, `t2`. The test must confirm
that the point at `t1` can change/cancel/reschedule the pending E2 work before
the `t2` transition, and that the internal event is not prematurely drained.

The integration gate also requires actual sequential classification on a
declared dataset/split and all applicable A01-A15 software-reference checks.
It must report prediction targets/errors, delayed credit, per-class results,
event counts, settling outcomes, local proxy units, boundedness and
deterministic replay. No accuracy threshold is created by this proposal.
An incomplete budget/horizon run is not reported as a complete pass.

## Why an implementation-only dispatch would have been insufficient

Before this ACP, implementation would have needed to choose when future
internal work may run relative to
external timestamps that have not entered the runtime, how one excursion maps
to Model-B and external readout, which event defines a prediction target, how
opaque error metadata propagates without becoming a numeric neuron input,
which identity owns delayed credit, what event ends a character, what reset
discards, and which serialized states can safely start an integrated network.
Those choices affect causal observables, predictive coding and readout
behavior. ACP-0004/0005 did not define all of them; ACP-0006 now defines the
accepted network-level composition. Treating them as incidental code details
before that decision could have created incompatible implementations or
silently altered normal experiment behavior.

## Expected benefits

- A single explicit migration boundary from scalar continuous output to
  event-only excursion output.
- Streaming-causal scheduling that cannot drain a future E2 event ahead of an
  unadmitted earlier input.
- Explicit, bounded contracts for prediction, error, eligibility, reward,
  readout, reset, settling and IR-2 startup.
- A matched legacy control without accidental model mixing or false numerical
  equivalence claims.
- Tests that distinguish silence from an emitted zero and internal temporal
  work from an unrelated input root.

## Expected disadvantages and risks

- A shared character queue and route-context sidecar add runtime orchestration
  state that must itself be finite and deterministic.
- Event-only output changes feature density and readout behavior; the retained
  external prototype mechanism may classify differently or be starved.
- The proposed local-error routing and causal-root sidecar require care around
  convergence, bounded duplicate suppression and provenance truncation.
- Fixed finite settling may leave pending work; all such incomplete results
  must remain visible rather than being reported as fully settled.
- IR-2 startup is intentionally much narrower than arbitrary runtime resume.
- Accepted architecture still requires software integration and independent
  adversarial verification; this proposal contains no execution evidence.

## Hardware implications

All choices are logical and hardware-neutral. FPGA/FPAA/GPU clocks, batch size,
register layout, sampling windows, quantization and physical spike timing do
not become neural time or canonical state. A bounded queue, stable logical
event identity, deterministic equal-time ordering, finite delays, event
budgets and explicit overflow remain software-reference requirements.

The sidecar route metadata and finite error-delivery guard must have declared
bounded representations for a future backend contract; this ACP does not
choose hardware bits, approximation tolerances, calibration or backend
mapping. Error events carry opaque logical metadata and use declared error
routes rather than changing Model-B numeric transfer. Event activity and
`abs(p_exc)` remain proxy accounting, not physical energy.

## Learning and energy implications

No learning algorithm is changed. Prediction values arise from canonical
excursion payloads and are compared only to a later causally observed input
payload. Eligibility arises only from emitted excursions; existing bounded
trace decay, signed error/reward delivery and reward message-idempotency
remain authoritative. Labels are used by external readout/reward orchestration
only after END_CHARACTER.

The proposed activity-cost proxy separates event-processing cost, excursion
amplitude and Model-B edge work. The utility formula and reward attribution
remain experimental and unchanged. Useful expensive work must remain
retainable. No physical-energy calibration is claimed.

## Compatibility and migration

Historical `TPCNNeuron` experiment runs remain reproducible from their
published source revisions. New runs identify one network-wide model and its
configuration. The explicit legacy control retains scalar/tanh behavior;
`EXCURSION_V1` routes only canonical excursions. Numeric trajectories are not
cross-model equality criteria.

ACP-0002 topology equations and fields, ACP-0004 E1/E2 state machines and
identity rules, ACP-0005 schema revision 1, standalone E1/E2 IR adapters,
prediction matching, eligibility/reward rules, classifier labels and
downstream-only TPCV semantics are not rewritten by this proposal. The
integrated network builder rejects mixed or unsupported model records. IR-2
does not gain a shared queue or predictor/ledger/readout serialization.

## Required experiments and acceptance criteria

Implement only the smallest CPU software-reference integration under the
separate numbered Luna authorization. Use fixed
topology, structural plasticity off, no N3/H2/backend/learning redesign, a
deterministic causal synthetic fixture, and then the first actual sequential
dataset protocol. Establish queue capacity, event budgets, settling horizon,
prediction capacity/expiry, provenance and readout caps before running.
