## Current invariant or soft constraint

The current contract requires event-driven execution, local elapsed-time state,
finite positive propagation, bounded topology and dynamics, local predictive
coding/learning, delayed credit compatibility, local resource accounting and
hardware-independent semantics. A01-A15 remain unchanged by this proposal.

The current implementation has a narrower edge object than the proposed
architecture: an edge stores endpoints, delay and routing cost, while the
destination neuron applies `input_gain` to the received payload. That is an
implementation limitation, not an existing A01-A15 requirement.

## Observed problem

**OBSERVED:** `tpcn.topology.Edge` currently stores only `source`,
`destination`, `propagation_delay` and `routing_cost`. `BoundedTopology.route()`
forwards the original payload. `TPCNNeuron.receive_event()` applies one
destination-owned nonnegative `input_gain` to every incoming payload.

**INFERRED:** This prevents one destination from receiving independently
parameterized connections and prevents future edge-local tuning, maturation or
credit attribution without placing edge state in the neuron or inventing a
second hidden path.

**HYPOTHESIZED:** A bounded edge-local transfer followed by the existing
delayed event queue will provide a cleaner hardware-neutral substrate while
preserving causal timing and local persistent integration. This proposal does
not claim that the substrate improves learning or task utility. The focused
mathematical review rejects the original subtraction form for the owner's
buffered-reference intent and selects the interpolation form below.

## Proposed change

### Canonical normalized domains

For the initial software reference, source activations and edge references are
normalized to `[-1, 1]`. The proposed finite domains are:

| Quantity | Domain | Meaning |
|---|---:|---|
| `w_ij` | `[-2, 2]` | signed edge efficacy; positive and negative coupling are distinct |
| `d_ij` | `[0, 1]` | nonnegative divider/coupling magnitude |
| `r_ij` | `[-1, 1]` | independent logical edge reference |
| `tau_ij` | finite `> 0` | existing edge-local propagation delay |
| `g_j` | `[0, 2]` | destination-neuron gain |
| `s_j` | `[-S_j, S_j]` | existing bounded persistent state |

The numeric limits are reference-model defaults, not physical voltage or
conductance claims. They must be configuration constants with finite validation
and may be compared in a later precision study. `w_ij` is signed because a
nonnegative efficacy cannot express inhibitory/reversing coupling; `d_ij` is
not signed because polarity belongs to the transformed signal and reference.

### Exact canonical edge equation

At source emission time, for a numeric source activation `a_i`:

```text
z_ij = f_E(w_ij * a_i)
v_ij = d_ij * z_ij + (1 - d_ij) * r_ij
arrival_time = emission_time + tau_ij
```

The canonical fixed reference transfer is:

```text
f_E(x) = tanh(x)
```

The scalar `v_ij` is placed in the delayed event payload. The edge is not
allowed to mutate the destination inline. The route must preserve event type,
source identity, destination identity, sequence ordering and causal timestamp
metadata. `d` and `r` remain separate fields and separate controls:

- with fixed `w` and `r`, changing `d` interpolates between the reference and
   transformed source signal;
- with fixed `w` and `d`, changing `r` changes the reference endpoint without
   changing source efficacy;
- two edges into one neuron may therefore have different references.

The owner-intended semantics are **Model B - divider reference endpoint**.
`r_ij` is an independently buffered logical reference level, and `d_ij` is the
signal-side interpolation weight. Thus `d=0` gives `v=r`, while `d=1` gives
`v=z`. This is not a shared neuron bias or destination midpoint. It is closest
to a normalized analog divider between a transformed signal node and an
independently buffered reference/virtual ground, while remaining a logical
scalar rather than a voltage equation. The convex-combination form has output
range `[-1, 1]`, so the edge itself cannot amplify a bounded normalized signal;
the destination state clip remains the recurrence guard.

The rejected Model A form, `d*(z-r)`, makes the reference contribution vanish
at `d=0` and scales the reference with coupling. It represents a local
zero-crossing or relative signal, not an independently established divider
endpoint. It is therefore not the canonical equation for this ACP.

`|w| <= 2` is a deliberate initial compromise: `tanh(2) ~= 0.964` at unit
input, retaining a useful transition region while bounding saturation. A later
precision experiment may compare smaller bounds; no learning rule is defined
here.

### Exact canonical neuron update

For an arriving edge event at local time `t_k`, with previous committed state at
`t_(k-1)` and `dt = t_k - t_(k-1)`:

```text
s_j(t_k-) = clip(s_j(t_(k-1)+) * exp(-lambda_j * dt), -S_j, S_j)
s_j(t_k+) = clip(s_j(t_k-) + v_ij(t_k), -S_j, S_j)
a_j(t_k) = f_N(g_j * s_j(t_k+))
f_N(x) = tanh(x)
```

Events are processed individually in timestamp/sequence order. Unequal delays
remain unequal, and no sum is evaluated as a synchronous neural timestep. A
neuron may emit its activation only after this event-local update. The fixed
edge and neuron nonlinearities are conceptually distinct (`f_E` and `f_N`)
even though both initially use `tanh`.

### Edge-state schema

The future edge record should contain bounded, explicit fields:

```text
Edge(
    source,
    destination,
    propagation_delay,
    routing_cost,
    efficacy=w_ij,
    divider_strength=d_ij,
    reference=r_ij,
)
```

The transfer parameters are logical state represented by finite software
scalars, not FPAA voltages. Initial edges use `w=1.0`, `d=1.0`, `r=0.0`; this
preserves the transformed source signal while making the reference explicit
for later tuning.
Edge parameters persist across character reset when topology persists; reset
of an edge parameter requires an explicit structural/topology reset policy.
Newly admitted edges must receive the same explicit bounded defaults until a
separately authorized policy defines another initialization. No edge tuning is
implemented by this ACP.

Future candidate creation, tuning, pruning, probation and maturation can act
on this record without moving edge-local state into the destination neuron.
Any temporary edge must later receive causal use and matured feedback before
structural usefulness is judged; possible evidence includes bounded edge-use
count, matured prediction/error consequences, local reward/eligibility and a
bounded event-time window. These are future requirements, not current state
machines.

### Neuron-state schema and legacy mapping

Neuron-owned state remains:

```text
neuron_id, state_limit, decay_rate, persistent_state, local_clock,
neuron_gain=g_j, activation, prediction_state, prediction_error,
eligibility_state, energy_state, processed_event_count
```

The current `input_gain` should become `neuron_gain` with the same bounded
nonnegative semantics and default value `1.0`, subject to the new
edge-transformed payload. It must no longer represent edge efficacy. A
compatibility constructor alias may be retained temporarily, with a clear
deprecation path, but stored state and new APIs should use `neuron_gain`.

The current raw-payload behavior cannot be reproduced exactly for every input
by `tanh(w*a)` with one scalar `w`. Therefore legacy comparisons need an
explicit `legacy_identity` edge-transfer mode or an adapter that sends the
old payload unchanged; it must not be mislabeled as the canonical `tanh`
path. The canonical defaults `w=1, d=1, r=0` are the cleanest normalized
defaults, but intentionally change the transfer to `tanh(a)` and must be
covered by an intentional test migration.

No destination-neuron reference is required. The delivered quantity is the
absolute normalized edge signal `v_ij`; adding a shared `r_j` would reintroduce
the very midpoint coupling that the per-edge `r_ij` field is intended to avoid.
The destination neuron integrates each arriving `v_ij` independently in event
order.

Predictive coding, explicit prediction-error events, eligibility and energy
accounting remain attached to local neuron/event components. Edge transformation
must preserve event identity and must not bypass prediction/error handling.

## Why implementation alone cannot solve it

This is a material ownership and interface decision: it changes the canonical
meaning of an edge, the payload entering the delayed queue, the distinction
between edge and neuron parameters, structural-growth defaults and hardware
mapping obligations. A code-only change could implement one behavior but would
leave the architecture ambiguous about signedness, bounds, reset persistence,
reference semantics and future learning/credit ownership. The existing
contract does not mandate an edge efficacy equation, so promotion requires a
recorded architecture decision. This ACP does not promote it while under
review.

## Expected benefits

- Independent edge efficacy, coupling magnitude and reference are observable.
- Edge-local transformation remains causal, finite-delay and hardware-neutral.
- Destination-neuron gain has one unambiguous owner.
- Structural growth can create complete bounded edge state.
- Later FPGA/FPAA mappings can independently represent conductance-like
  efficacy, divider strength and buffered reference without requiring voltage
  semantics in the CPU reference.

## Expected disadvantages and risks

- `tanh` at the edge compounds the neuron nonlinearity and can reduce small
  signal resolution; analytic saturation tests are mandatory.
- Defaults do not preserve raw-payload legacy behavior exactly.
- Reference endpoints can create signed contributions even when `w` is
   positive, so interpretation and energy accounting must remain explicit.
- Edge payload transformation changes existing traces and artifact digests.
- Topology rebuilds must preserve all edge parameters, or structural mutation
  silently resets learned/tuned state.
- No efficacy learning rule, utility benefit, hardware calibration or task
  improvement is implied.

## Hardware implications

The logical path maps later to an edge-local efficacy/conductance, fixed
saturating transfer, divider/coupling element, independently buffered
reference/virtual-ground abstraction and finite delay element. The proposal
does not require an op-amp, FPAA, memristor, DAC, resistor network or voltage
range. FPGA/VHDL and hybrid implementations must use finite-width fields and
must not turn a hardware clock into a neural timestep. FPAA precision and
reference calibration remain future hardware work. Edge transformation and
delay should be metered as local connection activity in the existing
uncalibrated resource model; no joule equivalence is claimed.

## Learning and energy implications

No learning rule is introduced. Future edge tuning must use information local
to the edge/source/destination and causally available messages. Prediction and
error events remain explicit and can carry edge identity for future bounded
eligibility attribution. Stable event/message identity and A11 retry-idempotent
reward behavior remain unchanged. Edge operations, transformed routed events
and any tuning work must eventually be represented in local activity-cost
proxies. Useful expensive computation must remain eligible for retention under
the existing reward-adjusted utility experiments; energy is not minimized by
silencing all edges.

Model A fails the reference-endpoint test at `d=0`: every reference produces
zero. Model B passes the endpoint tests, remains bounded, and preserves a
distinct source-side control. At `d=1`, both forms reduce to `z` only when
`r=0`; Model A otherwise retains a reference-dependent offset and can exceed
the normalized range. Positive and negative source activations remain
distinguishable under Model B, while `r` can make the delivered signal
excitatory or inhibitory relative to the destination state.

`w` and `d` are not redundant. `w` changes the signed pre-saturation transfer
shape, slope and saturation, including polarity. `d` changes the interpolation
between that transformed signal and the independently held reference. With
`r=0`, both affect amplitude locally, but only `w` changes nonlinear shape and
only `d` selects the reference endpoint. They represent distinct future
hardware quantities and both remain required.

Placing the fixed edge sigmoid before interpolation is appropriate: it bounds
the source branch before it is mixed with a bounded reference. Moving the
sigmoid after interpolation would make `r` alter the source efficacy curve and
would no longer model a divider between a transformed signal node and a
reference endpoint. Model B has a straightforward future analog interpretation
as a bounded signal/reference divider and remains hardware-neutral because the
software fields are normalized logical scalars.

Recurrence remains bounded: `z`, `r` and therefore `v` are in `[-1,1]`; each
arrival is clipped to `[-S_j,S_j]`; decay is non-expansive for nonnegative
`lambda_j`; and finite event/queue/lineage budgets still bound propagation.

## Required experiments and acceptance criteria

Before implementation approval, define seeded analytic fixtures for one edge,
two references, two divider strengths, two efficacies, positive/negative
source activation, edge and neuron saturation, unequal/equal delays,
persistent decay, bounded recurrence, fan-in, reset, deterministic replay,
structural-growth defaults, label isolation, no future leakage and observer
ON/OFF equivalence. Compare the identity adapter with the current raw-payload
reference where meaningful.

The focused implementation gate must also demonstrate event causality,
positive finite propagation, timestamp-preserving fan-in, no global neural
clock, bounded edge/neuron state, prediction/error preservation, delayed-credit
identity preservation, local resource accounting, deterministic replay and
batched/unbatched equivalence. Required A01-A15 acceptance checks remain
passed/not-run separately; no accuracy threshold is invented.
