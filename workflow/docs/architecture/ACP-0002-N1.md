# ACP-0002 Stage N1

Status: **Accepted for staged implementation**. This document records the N1
representation boundary only; it does not authorize N2 or activate Model-B.

## N1 state

`Edge` is a frozen, deterministic record containing `source`, `destination`,
positive finite `propagation_delay`, positive integer `routing_cost`,
`edge_weight` in `[-2, 2]`, `divider_strength` in `[0, 1]`, and `reference` in
`[-1, 1]`. New and legacy construction defaults are `edge_weight=1.0`,
`divider_strength=1.0`, `reference=0.0`, and `legacy_identity=True`.

`TPCNNeuron.neuron_gain` is the canonical destination-owned gain in `[0, 2]`
with default `1.0`. `input_gain` remains a read-only constructor/property alias
for compatibility. Supplying both aliases with different values is rejected.

Three-field topology tuples remain valid. Explicit `Edge` records are accepted
by topology construction and are preserved by structural growth rebuilds and
pruning rebuilds. Candidate association scores remain separate from edge
parameters; growth always uses the compatibility defaults.

## Propagation boundary

N1 does not compute or route:

```text
d * tanh(w * a) + (1 - d) * r
```

`BoundedTopology.route()` continues to enqueue the original event payload with
the original positive delay and event identity metadata. The canonical defaults
`w=1, d=1, r=0` are therefore not mathematically identical to raw routing once
N2 is enabled, because `tanh(a) != a` in general. Future work needs an explicit
legacy-transfer migration gate or adapter; that is outside N1.

Observers may inspect all edge fields. No new runtime resource charge is added
because N1 does not execute the future transfer.

ACP-0002 remains accepted for staged implementation. N2 is not authorized by
N1 completion. Luna-13F remains closed, Luna-13G remains unauthorized, and
A01-A15 remain unchanged.
