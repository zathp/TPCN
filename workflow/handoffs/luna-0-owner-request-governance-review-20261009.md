## Task-output, prediction, readout and reward findings

### Current governed interfaces

- **Actual neuron output:** `ExcursionEmission` is the canonical `EXCURSION`
  event and carries `event_id`, sequence, source, emission timestamp,
  signed payload, lineage and episode. Internal discharge/state and queued
  `S_EMIT` are not themselves the canonical output. Routing preserves a
  causal event and finite arrival delay. These are usable primitives, not
  an approved task-output channel/sink or mapping.
- **Native predictor:** `LocalPredictor` creates bounded
  `Prediction` IDs for numeric targets (`external-input:scalar` in the
  integrated adapter), from predictor-source actual emissions. It has a
  target key, predicted numeric value, creation time, optional expected
  resolution metadata and expiry. `expected_resolution_at` does not enforce
  a task deadline. Integrated ACP-0006 creates the local record but does not
  enqueue the task output through `emit_prediction()` as a
  `PREDICTION_EVENT`.
- **Errors and expiry:** a later matching numeric `Observation` can create
  an explicit, signed, causally routed `PREDICTION_ERROR_EVENT`.
  `expire()` removes unresolved records; it does not produce a missed-event
  error or silence outcome.
- **Streaming classifier/readout:** `StreamingCharacterClassifier` emits an
  A-Z `ClassificationResult` at `END_CHARACTER`. The integrated runtime
  feeds it actual readout-source emissions as `ACTIVITY_EVENT`s; it creates
  no event for silence. The result is not an event/deadline task output.
- **Outer experiment readout/reward:** the class prototype path is external
  to neural computation and updates from labels after readout. Integrated
  `end_character()` sends its reward to the first actual readout-source
  emission trace; if no readout emission exists, credit is unmatched.
  `EligibilityLedger.apply_signal()` changes bounded trace credit, not
  neuron/synapse parameters. Neither behavior is an owner-task learner.
- **ACP-0006 constraint:** eligibility is created only from actual canonical
  emissions; silent accumulator changes do not create a trace. Existing
  scalar reward/error signals require an existing `trace_id` or
  `prediction_id`; no current governed recipient exists for silence.

### Luna-13C external on-time/late fixture

Luna-13C is a genuine, governed **fixture-specific external evaluation**:
two fixed cue/probe cases use intervals 1.0 and 3.0, propagation delay 1.0,
deadline 3.0, fixed external targets `on_time` and `late`, and the rule
“second target-node arrival at or before 3.0 is on_time; otherwise late.”
It demonstrates that a downstream evaluator can distinguish an event-arrival
timing outcome from an independent fixed target without feeding that target
into structural learning.

It is not the needed owner-task output interface. Its `on_time`/`late`
decision is derived from target-node arrivals, not a declared canonical
neuron task-prediction event. The result stores the example/target/decision
and arrival timestamps but does not define the requested output identity,
target-event identity, output channel, first canonical emission decision,
duplicate policy, or a task-deadline queue survival/expiry/absence contract.
It covers neither negative-silence correctness nor ambiguous-prefix,
premature-output and omission-credit semantics. It must remain a Luna-13C
task fixture and cannot be generalized into the owner task by inference.

## Fixed/no-training and training viability

**Fixed/no-training:** Meaningful in principle once the owner approves a
real output observation boundary and freezes the task/evaluator. A downstream
evaluator can score a frozen mechanism without label-dependent reward,
prototype updates, parameter/topology changes, or cross-trial learning.
This path does not require omission credit, but it cannot be started for the
owner task until its output type/channel/identity, target schedule,
deadline/close, duplicates and silence adjudication are governed. The
Luna-13C fixture is a narrow precedent, not a substitute.

**Training/reward:** Not currently viable for the complete owner task under
existing governed interfaces. Actual-output cases may have source-local
emission traces, but task outcome-to-trace mapping and reward timing are
undefined. Missed positives and correct-silence trials have no task-output
trace or rewardable identity. The ledger stores scalar credit; current
outer prototype learning is a separate A-Z readout path. Any proposal to
create eligibility in silence, broadcast reward, use an unassigned trace, or
add a different learning consumer would need a separately bounded owner
decision and, where it changes accepted semantics, ACP review/acceptance.
No such interface is authorized here.
