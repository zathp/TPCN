## Source behavior versus contract requirement

The matrix distinguishes the frozen contractual classification from current
candidate O behavior. In particular, O:998–1007 selects a verdict before
finalization; O:1009–1037 writes/finalizes artifacts; an exception in that
block unconditionally sets `$Verdict='RP2_UNKNOWN_FAIL_CLOSED'` at O:1038
and calls `Alert-Unresolved`. If the report was already written at O:1033,
a later exception may leave the persisted report with an earlier verdict
while process state becomes UNKNOWN. This is a documented source/contract
reconciliation issue, not a source authorization or a replacement result.

Do not collapse “cannot PASS,” “incomplete evidence,” or “violates
transport” into an automatic new result. Do not assign a result by choosing
a seemingly conservative label when it changes accepted semantics. No new
result code or precedence is adopted in this analysis.
