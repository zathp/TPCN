# Luna-55 scientific successor selection

## Disposition

**LUNA-55 SCIENTIFIC EXPERIMENT AUTHORIZED — NOT EXECUTED.**

The single selected uncertainty is whether the 16 `DRIVE-LIMITED` streams
whose exact Luna-54 treatment arrivals cross the zero-decay oracle will
discharge at the finite destination-retention value when the independently
supported relay-retention change is also active.

## Evidence and post-Luna-54 partition

**OBSERVED:** Luna-54's independent review publication at
`d75ede92f90e7ba1e14f935eccbc26e3c326b8da` is PASS with high confidence
within its frozen setup. Its accepted endpoint is relay event generation and
successful propagation: the primary 75 streams gained 78 additional
discharge-linked, correctly received relay events in 65 streams. Destination
crossings remained 0/75. The pre-treatment blocked runner is not scientific
control evidence. Aggregate provenance's control-initial revision is a
non-blocking presentation caveat because each phase record retains its own
execution identity. Luna-0 did not rerun the previously reported Luna-54
tests.

The exact Luna-54 intervention destination arrivals were replayed offline
through the Luna-46 signed-prefix recurrence:

| Population | Streams | Historical arrivals | Luna-54 arrivals | Post-Luna-54 zero-decay result |
|---|---:|---:|---:|---|
| `DRIVE-LIMITED` E+ | 65 | included in 109 | included in 187 | 16 cross; 49 do not |
| `DRIVE-LIMITED` E0 | 10 | included in 109 | no additional arrivals | 0 cross |
| NR1 upstream-active | 189 | 0 | 65 in 58 streams | 0/58 responders cross; 54 complete-root responders, 4 retain truncation metadata |
| NR0 no-source-input | 23 | 0 | 0 | remains isolated |
| Historical temporal-retention-limited (secondary) | 33 | 126 | 169 | 33 zero-decay crosses; one actual crossing |

The 16 E+ target IDs are fixed in the contract and analysis artifact. Across
the 65 E+ streams there is no mixed-sign treatment arrival sequence, so the
distinction between the 16 zero-decay-sufficient and 49 zero-decay-insufficient
streams is not explained by newly introduced sign cancellation. The artifact
retains, for all 320 streams, control/intervention counts, signed and absolute
drive, positive/negative totals, historical/intervention/zero-decay peak,
threshold margins, crossing flags, event IDs, payload bits, timestamps, and
root-truncation metadata.

The signed zero-decay oracle is `z_k = z_(k-1) + payload_k` in the exact
retained arrival order, with initial state zero and `abs(z) >= 1` as the
threshold. Historical destination dynamics use
`z_k = z_(k-1) * exp(-0.0125 * dt_k) + payload_k`. The historical-rate
recurrence matched 252 primary/NR retained destination updates with zero
mismatches under the existing 64-binary64-epsilon verification rule. The
zero-decay calculation changed no retained event, payload, timestamp, or
order.

## Luna-53/Luna-54 factorial compatibility

**OBSERVED:** Luna-53 destination-only historical inputs and Luna-54 HH
arrivals match exactly across both initial and replay phases: all 320 streams,
235 arrivals, per-stream arrival order, event ID, payload bits, timestamp,
source/destination endpoints, and all 235 historical destination recurrence
traces. Destination configurations match exactly, and the pinned
`tpcn/event_runtime.py` and `tpcn/excursion_neuron.py` Git blobs are identical.
Thus existing L53/L54 evidence can supply the first three matched 2x2 cells;
the selection artifact and contract require the execution gate to repeat
these checks before reuse. The fourth cell must be executed as a complete
source-to-relay-to-destination run so that relay emissions are generated
causally under both factors.

## Candidate ranking and disposition

1. **Selected — serial retention composition.** Causal specificity is high:
   relay retention already changes output supply; destination retention is
   independently supported; exact same-stream arrivals identify 16 cases
   where total drive is sufficient but historical destination decay is not.
   The four factorial cells separate both main effects and their interaction.
2. **Not selected — more post-Luna-54 partition diagnostics.** The required
   target/control partition is now complete and persisted; another diagnostic
   would not add information before testing the predeclared finite
   destination-retention intervention.
3. **Not selected — destination gain/deposition experiment.** It would test a
   different mechanism despite an exact subgroup whose signed total drive is
   already sufficient. No gain scaling is justified.
4. **Not selected — remaining relay-generation diagnostic on E0.** Ten
   streams did not gain events, but this is not the dominant unresolved
   population; 65 streams did respond and 16 of those predict a specific
   serial bottleneck.

The composition outcome remains mechanistic only. The 49 zero-decay-
insufficient E+ streams are explicitly excluded from the target and remain
unresolved.

## Authorized design and validation record

Luna-55 is a fixed 2x2 design with the historical values (`0.0125` relay,
`0.0125` destination) and one independently supported retention value
(`0.00125`) for each factor. The sole new cell is the composed condition. All
other settings, route, topology, retained source input, and bounds are frozen.
The target is the 16 exact oracle-crossing streams; E+ zero-decay-noncrossers,
E0, NR1, and NR0 stay distinct controls. The contract predeclares per-stream
causal discharge/emission outcomes, route and recurrence gates, exact replay,
resource limits, and falsification rules.
