## Candidate ranking and decision

1. **Destination retention confirmation in existing E2** — highest causal
   discrimination. The independent target group (33) and two negative
   controls (75 drive-limited, 212 no-reception) are already defined. The
   treatment is a single predeclared tau800 value that produced partial
   target-only response in Luna-47A. It can now distinguish a scalar
   accumulator effect from the existing fast-state, sign-qualified,
   discharge/emission path.
2. **Propagation/bootstrap of the 212 no-reception streams** — potentially
   largest affected population, but current evidence records absence of
   reception without a source/relay intervention that distinguishes event
   generation, emission, and routing. It needs a separate upstream fixture
   and would not use the existing retention/drive subgroup split as a
   negative control.
3. **Drive/deposition** — clear mathematical result but already answered for
   the retained prefixes; high gain is not selective and creates no events
   where no receptions occur.
4. **Qualification** — a key risk, but actual Luna-46 inputs are already
   qualified; pre-qualification noise traces are unavailable. Another
   synthetic lane would not resolve the retained route uncertainty.
5. **Compression/output** — synthetic evidence only and not the current
   isolated bottleneck; changing it would add a second mechanism.
6. **Shortcut/fan-in topology** — no novel output associations, local source
   evidence, or demonstrated utility.
7. **Hardware/analog variation** — lacks calibrated physical parameters and
   owner-accessible build evidence; not suitable for the immediate causal
   question.

## Authorized experiment and limits

**One question:** does the single tau800 destination retention intervention
cause the existing ACP-0008 E2 neuron to discharge and emit canonically in
some of the previously retention-limited streams while both mechanistically
distinct control groups remain non-crossing?

**Control:** historical destination configuration, including
`decay_rate_z=0.0125`; replay all exact retained events through the E2
destination and require compatibility with retained baseline behavior.

**Intervention:** identical E2 destination and inputs, with only
`decay_rate_z=0.00125` (`tau_z=800`). This was fixed in Luna-47A before
outcomes; no rate sweep, `tau_z=8000`, input-gain adjustment, or other
parameter movement is allowed.

**Mechanistic negative controls:** all 75 `DRIVE-LIMITED` and 212
`NO-RECEPTIONS` streams. The former test whether retention is being mistaken
for insufficient signed drive; the latter ensure destination retention does
not fabricate arrivals.

**Primary measurements:** per-event `x/z` state, elapsed-time decay,
qualification, `z` threshold margin, sign check, integration discharge,
linked canonical E2 emission identity/time/payload, runtime bounds, and
control-group response. Category labels are evaluator-only. Use no upstream
network rerun and do not route emitted events onward.

**Supported outcome:** at least one target-only discharge with its linked
canonical emission, no such event in either negative-control group, exact
historical baseline compatibility, bounded execution, and deterministic
fresh-run replay. Target accumulation without canonical emission is at most
partial support. A nonselective response or no target discharge refutes the
declared hypothesis. A provenance/baseline/replay/boundedness failure blocks
interpretation.

Forbidden interpretations: task efficacy, improved prediction/classification,
useful network propagation, energy advantage, generalization, architecture
adoption, hardware equivalence, or proof that retention is the sole cause of
all Luna-46 failures.
