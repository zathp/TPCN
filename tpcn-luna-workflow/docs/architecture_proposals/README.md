# Architecture change proposals

Copy [ACP-TEMPLATE.md](ACP-TEMPLATE.md) to ACP-XXXX.md using the next unused number in this folder.

Lifecycle: Draft → Under review → Accepted or Rejected; accepted proposals may later be Superseded. Luna-0 reviews consistency and evidence. The project owner or explicitly delegated architecture decision-maker records acceptance. An agent's recommendation alone does not amend the contract.

An experiment may proceed within its authorized scope on an isolated experiment branch, with departures identified. It does not authorize promotion to core. Ordinary implementation changes preserving the contract do not require an ACP.

Acceptance must identify required evidence, affected clauses, compatibility and rollback. On promotion, update the contract and changelog together and link the implementation and verification handoffs. Retain rejected proposals as research history.
